Constructed global Banach additive-input integral solutions

Finite Picard solutions for an arbitrary globally Lipschitz Banach vector field are glued by proved common-input uniqueness. The result constructs an actual global norm-continuous solution with the specified initial value and additive integral equation on every nonnegative time.

Assumptions and formal scope. Assume a complete real Banach state space, a globally Lipschitz field, an initial state and continuous additive input starting at zero. A global solution is a conclusion. Negative times are continuously extended by the initial value; the equation is asserted for t≥0t\ge0t≥0.
