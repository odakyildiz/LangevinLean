Exact declarations · explicit assumptions

One simultaneous continuous original additive path version

A constructed joint drift representative has literal continuous pathwise primitives. Adding the actual raw input gives one jointly strongly measurable process version. Fubini transfers the original nonlinear drift equation on one full-measure spatial event for every time in the horizon, preserving every actual L² marginal.

Assumptions and formal scope. The raw additive input must be jointly strongly measurable, represent the actual L² input at each horizon time, and have almost-sure continuous paths. The L¹-time L² drift and actual integral equation are explicit; nonlinear drift continuity and its original L² realization are used. A pre-Brownian Driver alone does not supply sample-path continuity.
