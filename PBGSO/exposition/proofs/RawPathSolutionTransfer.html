PBGSO overview / PBGSO/RawPathSolutionTransfer.lean
Exact declarations · explicit assumptions

Source uniqueness transfers actual solution laws through Wiener paths

The proved initial/Wiener-path probability map pulls the canonical full mean-field strong solution to each original source. Source same-driver uniqueness then identifies original laws; a stationary weak frozen sampler on another source yields the literal stationary product law.

Assumptions and formal scope. A1 supplies one actual canonical full-system solution and same-driver uniqueness. A2 is interpreted as an actual stationary weak frozen SDE realization on some probability space. No common-source frozen strong solver, assumed input/output law, global drift moment or noise matching is supplied.
