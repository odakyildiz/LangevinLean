PBGSO overview / PBGSO/ParticleProcess.lean
Exact declarations · explicit assumptions

Constructed general interacting-particle integral dynamics

A single shared optimiser coordinate uses the actual empirical observation average. Primitive global Lipschitz bounds give an interacting-field constant independent of positive N. Picard then constructs norm-continuous L² integral solutions.

Assumptions and formal scope. The observation, response and sampler satisfy LipschitzDynamics; N is positive; the complete interacting initial state is L²; the additive input is L²-norm continuous and starts at zero. The theorem allows arbitrary additive input, so an application must separately set its optimiser component to zero and construct independent sampler Brownian inputs. No multiplicative-noise strong-SDE claim is made.
