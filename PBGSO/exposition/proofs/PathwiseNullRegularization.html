PBGSO overview / PBGSO/PathwiseNullRegularization.lean
Exact declarations · explicit assumptions

One common null regularization of progressive local energy

An actual ambient measurable null event makes local path integrability hold everywhere while preserving progressive windows and all original time sections off that event.

Assumptions and formal scope. Raw nonnegative progressive energy is only almost surely pathwise L1L^1L1. The null augmentation is explicit. A diffusion application must use the same mask for both the scalar energy and physical columns.

exists_nullAugmented_integrable_version

Mathematical role and assumptions

A raw progressive coefficient whose sample paths are locally time-L1L^{1}L1 almost surely admits a genuine progressive version with every path time-L1L^{1}L1. The construction changes only one ambient measurable null event, which the proved augmented Brownian filtration contains already at time zero.
