Parameter error by stationary and particle comparison

The parameter projection is assumed 111-Lipschitz in the complete optimiser norm. A stationary complete optimiser–sampler pair (s⋆,ν⋆)(s_\star,\nu_\star)(s⋆​,ν⋆​) is compared first with the mean-field solution and then with the empirical solution. The bound contains an exponentially decaying initial-law term and a finite-particle term of order N−1/2N^{-1/2}N−1/2.

Assumptions and formal scope. An original native interacting solution on independent whole seeds, natural original mean-field equations, initial P2\mathcal P_2P2​ and synchronous coordinates, primitive Borel maps, one-Lipschitz parameter projection, A3/A4/A5 and actual stationary target remain explicit. A1 supplies direct canonical/path strong-existence and uniqueness instances. The constant branch needs no universal finite work; the state-dependent branch uses primitive linear-growth regularity. No pair, noise/law compatibility, energy or final bound is supplied.

This particular comparison uses the response/variance hypotheses; it does not assume universal finite signed coupling work. □\square□

How the Lean proof follows this argument

original_parameter_bound_constant derives hVF using integral_nonneg and the initial variance bound. native_parameter_bias_bound provides both MemLp and the interaction-plus-relaxation estimate. RawNaturalConstantArbitraryLaw.law_decay supplies the actual stationary comparison with the stated canonical/path-source hypotheses. optimizer_norm_le_lawDistance discards the nonnegative transport component. The last line adds these inequalities and reorders the two terms. The projection and original native empirical state are retained in the conclusion.
