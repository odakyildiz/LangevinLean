Exact source parameter bounds for the original native empirical solution

The actual independent reference cloud and physical particle/copy pair are constructed internally. True initial Wasserstein relaxation and the sharp local particle floor give the original parameter L2L^2L2 bound in both A1 branches.

Assumptions and formal scope. An original native interacting solution on independent whole seeds, natural original mean-field equations, initial P2\mathcal P_2P2​ and synchronous coordinates, primitive Borel maps, one-Lipschitz parameter projection, A3/A4/A5 and actual stationary target remain explicit. A1 supplies direct canonical/path strong-existence and uniqueness instances. The constant branch needs no universal finite work; the state-dependent branch uses primitive linear-growth regularity. No pair, noise/law compatibility, energy or final bound is supplied.
