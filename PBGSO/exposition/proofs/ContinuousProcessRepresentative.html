PBGSO overview / PBGSO/ContinuousProcessRepresentative.lean
Exact declarations · explicit assumptions

One simultaneous jointly measurable continuous process version

Fixed-time measurability and almost-sure path continuity yield a jointly strongly measurable process with every path continuous and one full-measure event preserving every original time value.

Assumptions and formal scope. The time index is metrizable and second countable, and the state is a second-countable Borel normed space. No joint process version, adaptedness conclusion, stochastic law or moment is supplied.
