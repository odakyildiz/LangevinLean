Exact declarations · explicit assumptions

Natural target law relaxation on arbitrary original sources

Actual Wiener-path strong-solution transfer identifies original solutions with canonical comparison processes, then source A4/A5 derive target positive work and the true initial Wasserstein factor.

Assumptions and formal scope. A1 canonical actual existence and same-driver uniqueness, primitive Borel fields, actual stationary target and source A3/A4/A5 are visible. No growth, work, global moments, output-law equality or stronger process interface is supplied.

law_decay

Mathematical role and assumptions

Exact relaxation of an original natural raw solution on any Brownian source. The auxiliary existence/uniqueness inputs are direct A1 instances; output-law and stochastic matching are derived, and no drift-growth or work assumption is added to the source parameter hypotheses.

Read this statement with the module assumption note above. The complete proof appears alongside it; the full source preserves every shared variable and typeclass.
