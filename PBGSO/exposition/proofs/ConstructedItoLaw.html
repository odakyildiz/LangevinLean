PBGSO overview / PBGSO/ConstructedItoLaw.lean
Exact declarations · explicit assumptions

Actual state-dependent model law contraction from canonical data

Two actual canonical model trajectories are pulled to every initial coupling with a common full initial/noise filtration. Original equations, fixed marginal output laws, stochastic martingale/isometry identities and energy decay then pass to the actual Wasserstein infimum, giving the source condition-number contraction factor.

Assumptions and formal scope. This module takes actual canonical integral-equation data with Bochner L1L^1L1-time L2L^2L2 drift and continuous adapted L2L^2L2 diffusion. No all-couplings realizer, output-law equality or stochastic-interface premise remains. Identifying every source A1 strong solution with such data is still separate.
