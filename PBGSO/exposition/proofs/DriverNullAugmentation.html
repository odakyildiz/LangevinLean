Null augmentation preserves the actual Brownian Driver

Every augmented event has an original past event equal almost surely, preserving joint future independence and all Driver fields on the same ambient probability space. One AE continuous adapted process is regularized on one null event.

Assumptions and formal scope. Only ambient measurable null sets are added; the sample space and measure stay literal. No Brownian independence in the augmented filtration is assumed.
