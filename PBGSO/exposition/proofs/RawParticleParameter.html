Exact declarations · explicit assumptions

Original raw parameter error and joint large-time/particle limit

The exact raw particle interaction and actual one-Lipschitz parameter projection derive original parameter L2L^2L2 and RMS. Reference relaxation yields source4 constants, and a uniform family has joint time/particle limit zero.

Assumptions and formal scope. Raw particle hypotheses are inherited. This version explicitly supplies an actual reference weak solution, frozen weak stationarity, quadratic test domain and synchronous realization for every initial coupling; these are not inferred from an empty test family. No weak-particle equation, particle energy or parameter triangle conclusion is assumed.
