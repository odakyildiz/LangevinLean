Exact declarations · explicit assumptions

Invariant frozen kernels construct actual stationary sampler data

The actual jointly measurable frozen solver defines a transition kernel by Brownian-seed integration. Product Fubini identifies kernel action with original solver marginals, so kernel invariance derives all-time stationary sampler output laws.

Assumptions and formal scope. An actual frozen raw solver with the original initial coordinate is explicit. No marginal-law stationarity conclusion is supplied. Existence of a frozen strong solver or a weak-to-strong realization is not proved by this intermediate kernel construction.
