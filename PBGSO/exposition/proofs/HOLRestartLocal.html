Exact declarations · explicit assumptions

Actual printed Gaussian HOL local error with derived radii

Original Picard integral equations and Brownian increments derive every local moment and temporal modulus. The actual correlated-Gaussian local error is h sqrt(h) times an affine function of the input norm.

Assumptions and formal scope. Only primitive force regularity, alpha>0, gamma>=0 and the actual Brownian source are supplied. No reference moment, drift modulus, local-error or numerical stability conclusion is a premise.
