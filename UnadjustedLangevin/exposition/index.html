Run from the repository root

Install Git and elan first. The committed lean-toolchain and lake-manifest.json pin Lean and Mathlib. The initial cache download needs internet access.

lake build checks the formal proofs. Check.lean prints axiom dependencies. The Python commands regenerate the pages and check exact source excerpts, declaration coverage, LaTeX exports, and local links. Regeneration also needs Node.js; KaTeX and fonts are bundled.
