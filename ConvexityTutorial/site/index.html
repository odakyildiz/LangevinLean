Convexity in Lean

Rigorous elementary proofs, with the proof language explained from the beginning.

Reading a Lean declaration

ℝ
The type of real numbers. A type describes what sort of object a name denotes; x : ℝ declares a real number x.
theorem
Introduces a named mathematical statement together with its proof. A theorem name is an identifier chosen by its author.
def
Introduces a definition. Here, a definition ending in Prop names a mathematical property rather than a numerical value.
(f : ℝ → ℝ)
A parameter named f with type ℝ → ℝ: a function from real numbers to real numbers. The colon separates a name from its type.
(hf : IsConvex f)
A parameter named hf whose type is the proposition that f is convex. Supplying hf supplies a proof of that proposition.
( … )
Parentheses group an expression or enclose a named parameter with its type. In (x y : ℝ), both x and y have the type ℝ.
f x
Function application uses spaces. Read f x as f(x). The application binds more tightly than arithmetic: a * f x means a · f(x).
∀
For every. A proof of ∀ x, P x can be used at any particular x; intro names an arbitrary x while proving it.
,
In ∀ x, P x, the comma ends the bound variables and begins the statement about them. In a rewrite list such as [hab, one_mul], it separates two entries.
→
Between types, this is a function type. Between propositions, P → Q means that a proof of P can be used to construct a proof of Q.
: Prop
The defined expression is a proposition: a statement that may be proved. A proof is a term with that proposition as its type.
:= by
After the declaration's final colon comes its conclusion. := supplies its value or proof, and by starts a sequence of proof commands.
fun x ↦
Defines a function by its output at x. For example, fun x ↦ s * x + c is the function x ↦ sx + c.
* and +
Ordinary multiplication and addition of real numbers. Parentheses determine grouping. Equality =, inequality ≤, and strict inequality < are mathematical propositions.
⊢
The goal marker in Lean's proof-state display. The proposition after it remains to be proved from the named facts and data above it.
import
Makes definitions and proved facts from another Lean module available. Dots in the module name correspond to directories in its file path.
namespace
Groups declaration names. Inside namespace ConvexityTutorial, a theorem called convex_midpoint has the full name ConvexityTutorial.convex_midpoint.
/-- … -/
A documentation comment attached to the following declaration. It is explanatory text, not a proof command. -- begins a comment that ends with its line.
File setup and code conventions

Files and names

Each import loads checked declarations from another module. The namespace gives the project declarations a shared prefix. Comments describe the code and are not proof commands.

import ConvexityTutorial.Definitions
Load Definitions.lean and its imported declarations. Dots in a project module name correspond to folders.
namespace ConvexityTutorial
Prefix declared names with ConvexityTutorial.; end ConvexityTutorial closes this naming scope.
/-! … -/ and /-- … -/
Module and declaration documentation comments. Ordinary -- begins a comment extending to the end of its line.
set_option linter.style.header false
Disable one copyright-header style check for the remainder of the current file. It appears in Definitions.lean, Basic.lean, and Minimizers.lean, and changes no mathematical definitions or proof checking.

Read the types before reading the proof

A type specifies what an input is. Propositions are also types: a proof of a proposition is an expression whose type is that proposition. Therefore hypotheses can be passed to lemmas just like numerical inputs.

ℝ
The real numbers. The symbols and operations come from mathlib.
f : ℝ → ℝ
f is a function taking a real input to a real output.
f x
Function application, written with a space. It means f(x). Function application binds more tightly than arithmetic.
(f : ℝ → ℝ)
An explicit argument binder: the name precedes its type after the colon.
(x y a b : ℝ)
Four explicit real arguments, all with the displayed common type.
(hf : IsConvex f)
An explicit proof argument. The name hf is conventional; its declared type is what makes it a convexity proof.
Prop
The type of mathematical propositions.
∀ and →
∀ introduces arbitrary inputs. Between propositions, → introduces a premise that must be supplied as a proof.

Definitions and anonymous functions

A definition supplies an expression for a new name. An anonymous function supplies an input-to-output rule without introducing a separate named function.

def IsConvex (f : ℝ → ℝ) : Prop := …
Define the proposition IsConvex f by the quantified expression after :=.
fun x : ℝ ↦ s * x + c
The function sending x to s*x+c. The x after fun is bound only within this function expression.
(1 / 2 : ℝ)
A type annotation: one half is a real number. Lean can usually infer the types of other numerals from the expected real expressions.

Theorem statements and goals

A theorem names a proposition and provides its proof. A by block constructs that proof through tactics. Each displayed state lists the current context followed by ⊢ and the remaining proposition to prove.

theorem name (inputs) : conclusion := by
Name the theorem, declare its data and proof inputs, state its conclusion, then begin constructing the proof.
⊢
The goal marker in the state display. It is not part of the theorem source.
have h : P := proof
Add a proved local fact with name h and proposition P. A nested by block proves P before returning to the surrounding goal.
have h := proof
The same construction, with the proposition inferred from the proof term.
indentation
More-indented tactics belong to a nested local proof. Dedenting returns to the surrounding proof.
a b ha hb hab
Arguments separated by spaces are supplied from left to right, in the order of the lemma’s explicit binders. Some are real data and some are proofs.
False and ¬
False is the proposition with no proof; deriving it closes a contradiction. ¬ P means that a proof of P would imply False.

Order steps and algebraic steps

The proofs keep their mathematical reasons visible: convexity supplies inequalities; order lemmas combine them; rewriting uses equalities; arithmetic tactics check the remaining algebra. Every result is still checked by Lean’s kernel.

rw [h₁, h₂]
Rewrite with the named equalities in order. The equalities are used left to right in this tutorial.
rw […] at h
Rewrite inside the named fact h instead of the current goal.
calc
Link equalities and inequalities using their transitivity rules; every link has its own proof after :=.
ring
Prove a polynomial identity by checked commutative-ring normalization.
norm_num
Prove an exact numerical rational equality or inequality.
linarith
Prove the linear consequence or contradiction supplied by the current real equalities and inequalities.
How to read. Select one mathematical step to outline the corresponding code. The explanation below the code unpacks its syntax, and the proof state shows exactly what changed.

Proof 01 · ConvexityTutorial/Definitions.lean

Read a mathematical definition in Lean

The definition exposes every assumption of the chord inequality. Reading its binders correctly is enough to understand every convexity proof that follows.

Mathematical statement
\operatorname{IsConvex}(f)\iff\forall x,y,a,b\in\mathbb R,\quad a\ge0,\ b\ge0,\ a+b=1\Longrightarrow f(ax+by)\le af(x)+bf(y)

Mathematical proof

\operatorname{IsConvex}:(\mathbb R\to\mathbb R)\to\mathrm{Prop}

The new name IsConvex takes a function f as input and returns a proposition. Its definition will be the expression after := on the following lines. This is a declaration, so there is no tactic goal.

\forall x,y,a,b\in\mathbb R

The inequality must hold for every choice of two points x,y and two real weights a,b. The comma ends this binder list. Conditions restricting those weights appear on the next line.

a\ge0,\qquad b\ge0,\qquad a+b=1

Each implication arrow means: given a proof of this premise, continue to the remaining proposition. The three required proofs certify nonnegative weights whose sum is one. These are proof inputs rather than additional real numbers.

f(ax+by)\le af(x)+bf(y)

The left side evaluates f at the weighted point. The right side weights the two endpoint values. A proof of IsConvex must produce this inequality after receiving the four real inputs and the three premise proofs.

Proof 02 · ConvexityTutorial/Basic.lean
Affine functions: the first complete proof
An affine function preserves weighted averages exactly. This proof introduces goals, local hypotheses, rewriting, and a calculation chain while requiring only real algebra.
Mathematical statement
f(t)=st+c\quad\Longrightarrow\quad f\text{ is convex}
Mathematical proof
\text{Prove Jensen’s inequality for }f(t)=st+c.
The target is the named predicate IsConvex. Unfolding replaces it with its universally quantified chord inequality. No mathematical hypothesis has been added.
x,y,a,b\in\mathbb R,\qquad0\le a,\quad0\le b,\quad a+b=1.
Introduce the four arbitrary real inputs and then the three proofs required by the implication arrows. The order matches the definition exactly. The proof must now establish the chord inequality for these fixed but arbitrary inputs.
s(ax+by)+c\le a(sx+c)+b(sy+c)
Replace applications of the anonymous function by its defining formula. This is computation of a function body, so change checks definitional equality instead of requesting a new algebraic theorem.
A=B\Longrightarrow A\le B
Apply the order lemma backwards. The original non-strict inequality will follow from equality, so the new goal has the same two sides with an equals sign.
\begin{aligned}s(ax+by)+c&=s(ax+by)+(a+b)c\\&=a(sx+c)+b(sy+c).\end{aligned}
The first calculation link uses the weight-sum proof to insert a factor of one in front of the offset. The second link is a polynomial identity. Lean checks both links and composes their equalities, completing the equality goal and hence the original inequality.

Proof 03 · ConvexityTutorial/Basic.lean
Specialize convexity to a midpoint
A convexity proof is a reusable theorem with explicit inputs. Applying it at two half-weights yields the midpoint inequality; numerical side conditions and algebraic normalization are separate proof tasks.
Mathematical statement
f\text{ convex}\quad\Longrightarrow\quad f\!\left(\frac{x+y}{2}\right)\le\frac{f(x)+f(y)}2
Mathematical proof
0\le\tfrac12
Introduce a named proof of a concrete rational inequality. The type annotation selects the real number one half. The local numerical proof finishes without changing the main midpoint goal.
\tfrac12+\tfrac12=1
A second concrete rational calculation supplies the remaining numerical input required by the convexity definition.
f\!\left(\tfrac12x+\tfrac12y\right)\le\tfrac12 f(x)+\tfrac12 f(y)
Supply four real inputs and then three proof inputs to hf. The same nonnegativity proof is used twice because both weights are one half. The resulting inequality is named h.
\tfrac12x+\tfrac12y=\frac{x+y}{2}
Name a polynomial identity for the point inside the function. The algebra tactic treats x and y as arbitrary reals and checks the equality exactly.
\tfrac12 f(x)+\tfrac12 f(y)=\frac{f(x)+f(y)}2
Prove the analogous identity for the real function values. No property of f is used in this algebraic step; its two values can be treated as real expressions.
h:\quad f\!\left(\frac{x+y}{2}\right)\le\frac{f(x)+f(y)}2
Use the two equalities inside the named inequality. The current main goal stays the same; it is the type of the known proof h that changes to match that goal.
f\!\left(\frac{x+y}{2}\right)\le\frac{f(x)+f(y)}2
The rewritten h has exactly the target proposition as its type. Providing this proof finishes the theorem.

Proof 04 · ConvexityTutorial/Basic.lean
Add two convex functions
Closure under addition is proved by adding the two Jensen inequalities at the same points and weights. The proof separates an order argument from a final algebraic rearrangement.
Mathematical statement
f,g\text{ convex}\quad\Longrightarrow\quad t\mapsto f(t)+g(t)\text{ is convex}
Mathematical proof
\text{Prove the chord inequality for }t\mapsto f(t)+g(t).
Expand the definition of convexity for the sum function. The existing convexity proofs for f and g remain available in the context.
x,y,a,b\in\mathbb R,\qquad a,b\ge0,\quad a+b=1.
Fix the four arbitrary real inputs and their weight proofs. Both component inequalities must use this same data so that they can be added.
f(ax+by)\le af(x)+bf(y)
Apply the supplied proof hf to the fixed points, weights, and three weight-condition proofs. Name the resulting inequality h_f.
g(ax+by)\le ag(x)+bg(y)
Apply hg to exactly the same inputs. The two inequalities now have aligned coefficients and arguments.
f(ax+by)+g(ax+by)\le a(f(x)+g(x))+b(f(y)+g(y))
Compute the anonymous function at the weighted point and at the endpoints. The target is restated using the two functions separately.
\begin{aligned}f(ax+by)+g(ax+by)&\le(af(x)+bf(y))+(ag(x)+bg(y))\\&=a(f(x)+g(x))+b(f(y)+g(y)).\end{aligned}
The first link is the order lemma for adding inequalities. The second is distributivity and rearrangement in the reals. The calculation chain proves the target.

Proof 05 · ConvexityTutorial/Basic.lean
Scale a convex function by a nonnegative constant
The sign restriction enters at one precise order step. Multiplying Jensen’s inequality by a nonnegative constant preserves its direction; the remainder is algebra.
Mathematical statement
f\text{ convex},\quad c\ge0\quad\Longrightarrow\quad t\mapsto cf(t)\text{ is convex}
Mathematical proof
\text{Prove Jensen’s inequality for }t\mapsto cf(t).
Expand IsConvex. Keep both the original convexity proof and the separate proof that the scaling factor is nonnegative.
x,y,a,b\in\mathbb R,\qquad a,b\ge0,\quad a+b=1.
Introduce the points, weights, and weight proofs required by the convexity definition.
f(ax+by)\le af(x)+bf(y)
Apply the original convexity proof at the chosen data. This is the inequality to multiply by c.
cf(ax+by)\le a(cf(x))+b(cf(y))
Compute the anonymous function in the target, leaving an explicit scalar inequality.
cf(ax+by)\le c(af(x)+bf(y))=a(cf(x))+b(cf(y))
The order lemma receives both the original inequality and the sign proof hc. It preserves the comparison when multiplying on the left. The equality link then distributes and reorders products.

Proof 06 · ConvexityTutorial/Minimizers.lean
Convex combinations of minimizers remain minimizers
This is an optimization consequence of the chord inequality. It assumes two global minimizers are already given; it does not assert that a minimizer exists.
Mathematical statement
\begin{gathered}f\text{ convex},\quad x,y\in\operatorname{argmin}f,\quad a,b\ge0,\quad a+b=1\\\Longrightarrow\quad ax+by\in\operatorname{argmin}f.\end{gathered}
Mathematical proof
f(y)\le f(x),\quad f(x)\le f(y)\quad\Longrightarrow\quad f(y)=f(x)
By definition, hx compares f(x) with every function value, and hy does the same for f(y). Evaluate them at the opposite points. Antisymmetry turns the two comparisons into an equality of minimum values.
f(ax+by)\le af(x)+bf(y)=(a+b)f(x)=f(x)
Introduce a local upper bound and prove it by a calculation chain. First apply convexity. Replace f(y) by f(x), collect coefficients with ring, then use the weight sum to get f(x).
\forall z\in\mathbb R,\quad f(ax+by)\le f(z)
Expand the minimizer definition. It requests a comparison with every real point, not merely with the two endpoints.
z\in\mathbb R\quad\text{arbitrary}
Introduce a completely arbitrary real z. Proving the comparison for this arbitrary input proves the universal claim.
f(ax+by)\le f(x)\le f(z)
Use the established upper bound for the first link. The global-minimum proof hx, evaluated at z, supplies the second. Transitivity of order proves that the combined point is a global minimizer.

Proof 07 · ConvexityTutorial/Subgradients.lean
A horizontal supporting line certifies a global minimum
A supporting line is an explicit global inequality. With slope zero it is exactly the global-minimum comparison. No differentiability or additional convexity assumption is required for this implication.
Mathematical statement
\bigl[\forall y,\ f(x)+0\,(y-x)\le f(y)\bigr]\quad\Longrightarrow\quad x\in\operatorname{argmin}f
Mathematical proof
\text{Fix arbitrary }y\in\mathbb R;\quad\text{prove }f(x)\le f(y).
The target IsGlobalMinimizer unfolds as needed when intro encounters it. Introduce its arbitrary comparison point y. The supporting-line assumption remains available.
f(x)+0\,(y-x)\le f(y)
Apply the supplied universal supporting-line proof to y and name the resulting inequality h.
f(x)\le f(y)
Simplify only the product by zero and the resulting addition by zero in h. The simplified proof has the exact target type, so simpa completes the goal.

Proof 08 · ConvexityTutorial/Subgradients.lean
Supporting slopes are monotone
Two supporting-line certificates already contain a monotonicity theorem. Adding them cancels the function values and yields an inequality involving only the points and slopes. The slopes are not assumed to be derivatives.
Mathematical statement
\operatorname{SupportsAt}(f,x,g_x),\quad\operatorname{SupportsAt}(f,y,g_y)\quad\Longrightarrow\quad0\le(g_y-g_x)(y-x)
Mathematical proof
f(x)+g_x(y-x)\le f(y)
Apply the support proof hx to the other point y. The locally named inequality hxy is the first half of the cancellation argument.
f(y)+g_y(x-y)\le f(x)
Apply hy to x, producing the opposite-direction support inequality hyx.
g_x(y-x)+g_y(x-y)\le0
Introduce the displayed sum inequality as a local goal. Linear arithmetic adds the two known support inequalities and cancels f(x) and f(y). No derivative or strict-convexity theorem is involved.
0\le-[g_x(y-x)+g_y(x-y)]=(g_y-g_x)(y-x)
Negating a nonpositive quantity makes it nonnegative. The first link applies that order equivalence to hsum. The second link is the algebraic identity that factors the negated sum into the change of slope times the change of point.

Optional proof 09 · ConvexityTutorial/Minimizers.lean
Optional: strict convexity makes a minimizer unique
Strict convexity rules out two distinct global minimizers by testing their midpoint. This final example adds proof by contradiction and combines already familiar numerical and order steps. It assumes minimizers are given and proves uniqueness, not existence.
Mathematical statement
f\text{ strictly convex},\quad x,y\in\operatorname{argmin}f\quad\Longrightarrow\quad x=y
Mathematical proof
\text{Assume }x\ne y\text{ and derive a contradiction}.
Proof by contradiction assumes the negation of the equality target under the name hxy. The remaining goal becomes False. This assumption is exactly the distinct-point input required by strict convexity.
0<\tfrac12
Strict convexity needs positive weights. The concrete rational inequality is checked exactly.
\tfrac12+\tfrac12=1
The familiar weight-sum equality supplies the other numerical input.
f(\tfrac12x+\tfrac12y)<\tfrac12f(x)+\tfrac12f(y)
Supply the points, weights, distinctness proof, two positivity proofs, and weight-sum proof to hf. This is the strict version of the earlier midpoint application.
f(y)=f(x)
Evaluate each global-minimum proof at the other point and apply antisymmetry, exactly as in the convex-combination lesson.
f(\tfrac12x+\tfrac12y)<\tfrac12f(x)+\tfrac12f(x)
Replace f(y) with f(x) in the known strict inequality. This modifies the hypothesis hstrict while the current goal remains False.
f(x)\le f(\tfrac12x+\tfrac12y)
Global minimality of x applies to every point, including this midpoint. Name that comparison hminimal.
f(x)\le f(\tfrac12x+\tfrac12y)<f(x)
The strict upper bound and the minimum lower bound contradict one another after collecting the half coefficients. Linear arithmetic proves False, closing the contradiction and establishing x = y.
