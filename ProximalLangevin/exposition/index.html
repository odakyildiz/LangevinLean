Corrected MYIPLA, PIPGLA, and MYPGD original-center bounds are proved. This is a partial formalization of arXiv:2406.14292v3: exact published constants and several appendix claims remain outside the proved results. The reference audit records the differences.

Reproduce the formal proof

Install Git and elan, Lean’s toolchain manager, before cloning. The repository pins the Lean and Mathlib versions. The first cache download requires an internet connection.

lake build checks the Lean proofs. The audit file prints the logical axioms used by the results. The local check script also verifies that every displayed source excerpt matches the repository and that the mathematical pages regenerate correctly. Documentation generation requires Python 3 and Node.js.
