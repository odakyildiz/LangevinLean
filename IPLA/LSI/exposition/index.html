01The geometry fixes the dimension, gradient constant, and step §

Each physical pair (θ,xi)(\theta,x^i)(θ,xi) is extracted from the scaled state by (θ,Nzi)(\theta,\sqrt N z_i)(θ,N​zi​). Differentiating the lifted sum gives the averaged parameter drift and ordinary latent drifts at step γ/N\gamma/Nγ/N. The corresponding Euclidean state has

D=dθ+Ndx,LN=NL,hN=γ/N.D=d_\theta+Nd_x,\qquad L_N=NL,\qquad h_N=\gamma/N.D=dθ​+Ndx​,LN​=NL,hN​=γ/N.

The parameter block of the lifted gradient is a sum over particles; each latent block contributes a factor N\sqrt NN​. Squaring and summing the blocks, then applying Cauchy–Schwarz to the common-parameter sum, proves the gradient Lipschitz constant NLNLNL. The coordinate Gaussian laws and independence identify the actual noise-driven IPLA law with this ULA transition. No equality between dθd_\thetadθ​ and dxd_xdx​ is needed.

The lifted geometry and identification with the actual Gaussian particle algorithm are checked.

Iteration gives the unnormalized floor

04Project to the parameter marginal using data processing §

Let PθP_\thetaPθ​ be the parameter projection, μkθ=Pθ#μk\mu_k^\theta=P_{\theta\#}\mu_kμkθ​=Pθ#​μk​, and ΠNθ=Pθ#ΠN\Pi_N^\theta=P_{\theta\#}\Pi_NΠNθ​=Pθ#​ΠN​. Relative entropy decreases under a measurable map:

HΠNθ(μkθ)≤HΠN(μk).H_{\Pi_N^\theta}(\mu_k^\theta)\le H_{\Pi_N}(\mu_k).HΠNθ​​(μkθ​)≤HΠN​​(μk​).

This controls the unnormalized parameter KL. In particular, under βN=Nα\beta_N=N\alphaβN​=Nα,

HΠNθ(μkθ)≤e−αγkHΠN(μ0)+8γNL2α(dx+dθN).H_{\Pi_N^\theta}(\mu_k^\theta) \le e^{-\alpha\gamma k}H_{\Pi_N}(\mu_0) +\frac{8\gamma NL^2}{\alpha}\left(d_x+\frac{d_\theta}N\right).HΠNθ​​(μkθ​)≤e−αγkHΠN​​(μ0​)+α8γNL2​(dx​+Ndθ​​).

The initial entropy remains the full joint entropy. Data processing does not allow it to be replaced by the smaller initial parameter entropy on the right. Likewise, a normalized joint bound must be multiplied by NNN before it bounds the unscaled parameter KL. The Lean proof establishes finite joint KL, transfers finiteness to the marginal, and only then compares the real values.

The parameter data-processing argument and all normalization factors are checked. This conclusion concerns a probability marginal, not distance to a likelihood maximizer.
