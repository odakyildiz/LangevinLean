Langevin Monte Carlo with Average Smoothness

Exact deterministic lemmas, conditional rates, and a counterexample to the Gaussian design proposition.

Supplied manuscript; incomplete formalization and source obstruction

The exact supplied manuscript is the correspondence authority. Deterministic smoothness and gradient lemmas and conditional scalar recurrences are checked. An allowed quadratic-plus-sine GLM contradicts the dimension independent isotropic Hessian Lipschitz bound in Proposition 2. The Gaussian probability obstruction is checked using exact moments. The actual-law LMC, Laplacian-smooth LMC and SGLD convergence theorems remain unproved; a full formalization with the printed hypotheses and conclusions is impossible without correcting Proposition 2.

  • Arnak S. Dalalyan and Avetik Karagulyan (undated manuscript). Improved Guarantees for Langevin Monte Carlo with Average Smoothness. Supplied Arxiv_version_May_26.tex; publication status not established.

Incomplete. The supplied Gaussian design proposition is false with its printed dimension independent constants. Its exact full-paper formalization is impossible. The actual-law convergence theorems remain unproved; checked components are identified below.

Reproduce the formal proof

Install Git and elan, Lean’s toolchain manager, before cloning. The repository pins the Lean and Mathlib versions. The first cache download requires an internet connection.

lake build checks the Lean proofs. The audit file prints the logical axioms used by the results. The local check script also verifies that every displayed source excerpt matches the repository and that the mathematical pages regenerate correctly. Documentation generation requires Python 3 and Node.js.
