Latin Modern webfonts

These four WOFF2 files are the Latin Modern fonts used by odakyildiz.com:
https://odakyildiz.com/fonts/LM-regular.woff2
https://odakyildiz.com/fonts/LM-italic.woff2
https://odakyildiz.com/fonts/LM-bold.woff2
https://odakyildiz.com/fonts/LM-bold-italic.woff2

Latin Modern is by Boguslaw Jackowski and Janusz M. Nowacki, based on
Donald E. Knuth's Computer Modern. It is distributed under the GUST Font
License; see GUST-FONT-LICENSE.txt and LPPL.txt in this directory.

The files are bundled for offline reading. Current pages load them from
the local assets directory; standalone archived documents embed them.
