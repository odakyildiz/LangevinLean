\section{An invariant-subspace principle}


Let \(S\) be a complete submodule with \(g(S)\subseteq S\), \(x\in S\), and \(B_t\in S\) on \([0,T]\). Solve the equation inside \(S\), then include its solution into the ambient space. Continuous linear inclusion commutes with the integral, so the included path solves the original equation. Uniqueness identifies it with \(Y\), proving \(Y_t\in S\).

\section{Measurability is preserved by the lifted drift}


If \(X\) is almost everywhere strongly measurable with respect to a sub-sigma algebra \(\mathcal G\), continuity of \(g\) implies the same for \(g(X)\). The lifted drift agrees almost everywhere with this composition. The \(L^2\) classes measurable with respect to \(\mathcal G\) form a complete submodule; applying the preceding invariant-subspace theorem shows \(Y_t\) is \(\mathcal G\)-measurable whenever its initial value and all noise inputs up to the horizon are.

\section{The natural past sigma algebra}


Define \(\mathcal G_T=\sigma(X_0,B_t:0\le t\le T)\) as the supremum of the corresponding pullback measurable spaces. Measurability of each \(L^2\) representative proves \(\mathcal G_T\) lies below the ambient sigma algebra; its definition makes the initial value and each noise value at time \(t\le T\) measurable. Insert these facts into the smaller-sigma-algebra result to obtain measurability of \(Y_t\) with respect to its natural past.
