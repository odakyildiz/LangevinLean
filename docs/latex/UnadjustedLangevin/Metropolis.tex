The Metropolis correction preserves the initial marginal whenever the accepted proposal flow is invariant under swapping its two states. A positive proposal-pair density makes this symmetry explicit.


\section{Split the proposal flow}


For a joint proposal measure \(\nu(dx,dy)\) and a measurable acceptance \(0\le a\le1\), define accepted flow \(a\nu\), rejected flow \((1-a)\nu\), and output \((a\nu)_2+((1-a)\nu)_1\). Since \(a+(1-a)=1\), the two weighted measures sum to \(\nu\). A swap-invariant measure has equal first and second marginals. Therefore, if the accepted flow is swap invariant, its second marginal can be replaced by its first, and the output is \(\nu_1\).

\section{Weights commute with measurable pushforward}


For measurable \(f\) and weight \(w\), integrating indicators and using the pushforward formula proves \(f_\#[(w\circ f)\mu]=w(f_\#\mu)\). The measurable-equivalence version specializes this identity. It allows an accept/reject rule defined in proposal-pair coordinates to be moved through a proposal-generating transformation.

\section{The Metropolis minimum is symmetric}


For a strictly positive density \(w(x,y)\), set \(a(x,y)=\min\{1,w(y,x)/w(x,y)\}\). Then

\[w(x,y)a(x,y)=\min\{w(x,y),w(y,x)\}.\]

Thus the accepted flow has the symmetric minimum density. If the base measure is swap invariant, so is this weighted flow. Apply the accepted/rejected decomposition to conclude exact preservation of the initial marginal. Positivity of \(w\) justifies the ratio algebra.
