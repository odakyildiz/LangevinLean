Let \(N>0\), let \(g_1\) be differentiable and \(m\)-strongly convex with \(L_1\)-Lipschitz gradient, and let \(g_2\) be convex and bounded below. Assume \(0<m\le L_1\), \(\lambda>0\), and \(0\le\gamma\le2/(m+L_1)\). These are deterministic comparisons of two chains with the same innovations.


\section{Jensen handles two independently averaged outputs}


Apply the scalar average-square inequality to the difference of the parameter outputs. Each latent difference has its exact scaled square. Thus

\[\|\operatorname{Pair}_P(z)-\operatorname{Pair}_P(w)\|^2\le N^{-1}\sum_i\|P(J_i z)-P(J_i w)\|^2.\]

If \(P\) is nonexpansive, each summand is bounded by \(\|J_i(z-w)\|^2\). Their sum is \(N\|z-w\|^2\), proving that the actual pairwise map is also nonexpansive.

\section{A shared innovation cancels before proximity}


The lifted smooth gradient step has strong convexity \(Nm\), gradient constant \(NL_1\), and step \(\gamma/N\), so its contraction factor is \(1-m\gamma\ge0\). The same Gaussian or deterministic innovation added to both inputs cancels in their difference. Composition with the actual nonexpansive averaged proximal map gives

\[\|T_\lambda(z,\xi)-T_\lambda(w,\xi)\|\le(1-m\gamma)\|z-w\|.\]

Induction on the displayed recursion yields factor \((1-m\gamma)^n\). This proves stability; a separate stationary reference and local-consistency estimate are needed for convergence to a Gibbs target.
