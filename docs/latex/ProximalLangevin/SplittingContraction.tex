Draft mathematical exposition; these notes may contain mistakes.


For the actual splitting map, parameter averaging preserves nonexpansiveness of each joint proximity map. A shared innovation cancels before proximity, so the strongly convex smooth forward contraction survives the composition. This proves pathwise stability for every supplied innovation sequence and every positive proximal scale.




Let \(N>0\), let \(g_1\) be differentiable and \(m\)-strongly convex with \(L_1\)-Lipschitz gradient, and let \(g_2\) be convex and bounded below. Assume \(0<m\le L_1\), \(\lambda>0\), and \(0\le\gamma\le2/(m+L_1)\). These are deterministic comparisons of two chains with the same innovations.



Earlier results used here: \cite[Section~3.7]{LangevinLean2026IPLA}; \cite[Section~3.10]{LangevinLean2026ULASC}.

\section{\texorpdfstring{Jensen handles two independently averaged outputs}{Jensen handles two independently averaged outputs}}


Apply the scalar average-square inequality to the difference of the parameter outputs. Each latent difference has its exact scaled square. Thus

\[\|\operatorname{Pair}_P(z)-\operatorname{Pair}_P(w)\|^2\le N^{-1}\sum_i\|P(J_i z)-P(J_i w)\|^2.\]

If \(P\) is nonexpansive, each summand is bounded by \(\|J_i(z-w)\|^2\). Their sum is \(N\|z-w\|^2\), proving that the actual pairwise map is also nonexpansive.




Put \(A_i z=(\theta,\sqrt N z_i)\) and \(\Delta_i=P(A_i z)-P(A_i w)\). The shared parameter is an average, so Jensen gives \(N\|\overline\Delta_\theta\|^2\le\sum_i\|\Delta_{i,\theta}\|^2\); each latent coordinate is rescaled by \(N^{-1/2}\), so its corresponding squared identity is exact. Summing yields \[\|\operatorname{Pair}P(z)-\operatorname{Pair}P(w)\|^2\le\frac1N\sum_i\|\Delta_i\|^2.\] Nonexpansiveness of \(P\) and \(\sum_i\|A_i(z-w)\|^2=N\|z-w\|^2\) prove the claimed state-space bound. The positivity of \(N\) justifies both division and the unscaling.





The two averaged parameter outputs need not coincide pair by pair. Jensen handles their average difference, while latent squares have exact scaled identities. Applying pairwise nonexpansiveness and the replication identity gives a unit Lipschitz constant for the entire averaged map. No assertion that this map is a shared-state proximal minimizer is used in the argument.



Earlier results used here: \cite[Section~3.1.1]{LangevinLean2026IPLA}; \cite[Section~3.1.2]{LangevinLean2026IPLA}.

\section{\texorpdfstring{A shared innovation cancels before proximity}{A shared innovation cancels before proximity}}


The lifted smooth gradient step has strong convexity \(Nm\), gradient constant \(NL_1\), and step \(\gamma/N\), so its contraction factor is \(1-m\gamma\ge0\). The same Gaussian or deterministic innovation added to both inputs cancels in their difference. Composition with the actual nonexpansive averaged proximal map gives

\[\|T_\lambda(z,\xi)-T_\lambda(w,\xi)\|\le(1-m\gamma)\|z-w\|.\]

Induction on the displayed recursion yields factor \((1-m\gamma)^n\). This proves stability; a separate stationary reference and local-consistency estimate are needed for convergence to a Gibbs target.




In one shared-noise comparison, the additive Gaussian vector cancels before applying the pairwise proximal map. The smooth forward step contracts by \(q=1-m\gamma\); the actual proximal minimizer is nonexpansive, so composing the two leaves the same factor. The step restriction proves \(q\ge0\), which is needed to multiply the induction inequality. Starting with \(e_0=\|z-w\|\), the successor case gives \(e_{k+1}\le q e_k\le q^{k+1}e_0\). This establishes pathwise stability under arbitrary supplied innovations, without stationarity or independence assumptions.





For the same innovation, the pre-proximal state difference is exactly the deterministic smooth forward difference. Its contraction factor is \(q=1-m\gamma\), which is nonnegative under the stated restriction. Composing with a nonexpansive map gives \(e_{k+1}\le q e_k\). Induction yields \(q^n e_0\), independently of Gaussianity or independence, because only equality of the innovations is needed.
