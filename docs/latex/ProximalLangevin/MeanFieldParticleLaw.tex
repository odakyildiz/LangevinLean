The constructed tagged particle and its actual reference copy live on one probability space, giving an explicit finite-cost coupling of their one-time joint laws. The copy law is exactly the original mean-field law. Their coordinate \(L^2\) comparison therefore implies a Wasserstein rate while preserving the actual particle integral equation and noise construction.



\section{\texorpdfstring{A measure-\allowbreak{}preserving copy has exactly the reference law}{A measure-preserving copy has exactly the reference law}}


The copy representative equals \(X(\omega_i)\) almost everywhere. Product-coordinate evaluation pushes \(Q^{\otimes N}\) to \(Q\), so the pushforward composition formula proves \(\mathcal L_{Q^{\otimes N}}(C_iX)=\mathcal L_Q(X)\). The almost everywhere change of representative does not affect the law.





The copy is obtained by evaluating the original variable on one product coordinate. That evaluation pushes the product source to the original source measure. Composing pushforwards consequently gives the same law as the original variable. Almost-sure representative changes do not affect this equality, so the copied reference in the eventual coupling has precisely the intended mean-field marginal.


\section{\texorpdfstring{Use the actual tagged joint pair as a coupling}{Use the actual tagged joint pair as a coupling}}


On the product space couple the actual pair \((\Theta^N,X_i^N)\) with the genuine iid copy of \((\theta,X)\). Both are \(L^2\), so the coupling has finite cost. The joint-pair norm bound gives

\[W_2(\mathcal L(\Theta^N,X_i^N),\mathcal L(\theta,X))\le\|\Theta^N-\theta\|_2+\|X_i^N-X_i\|_2.\]

Finiteness is established before converting the extended transport value to a real number.




On the finite product space use the explicit pair consisting of the actual tagged particle \((\Theta_t^N,X_t^{i,N})\) and the genuine joint iid reference copy. Measure-preserving coordinate evaluation proves that the latter has exactly the original mean-field law. This pair is an admissible finite-cost coupling because both random variables are in \(L^2\). Its cost is bounded by the sum of the parameter and tagged-latent \(L^2\) differences, yielding the displayed Wasserstein estimate. The public theorem inserts the constructed coordinate comparison and keeps the actual Brownian particle integral equation in its conclusion, so the law bound refers to the specified process.





Reconstruct the tagged joint pair from the common particle parameter and its \(i\)-th latent coordinate. Couple it with the corresponding iid mean-field pair on the same product source. Their joint distribution has the required two marginal laws and finite quadratic cost. The pair norm is bounded by the sum of coordinate norms; Minkowski gives the same inequality in \(L^2\), and transport is no larger than this explicit coupling cost.

\section{\texorpdfstring{Retain the true Brownian input in the final law theorem}{Retain the true Brownian input in the final law theorem}}


The joint pair \((\Theta_t^N,X_t^{i,N})\) has finite second moment, and each reference copy has exactly the actual law of \(Y_t=(\theta_t,X_t)\). Their constructed joint distribution is an admissible coupling. The pair L\ensuremath{{}^{2}} norm is at most the sum of its coordinate norms, giving


\[
W_2\!\left(\mathcal L(\Theta_t^N,X_t^{i,N}),\mathcal L(\theta_t,X_t)\right)
 \le\frac{C_T}{\sqrt N},\qquad 0\le t\le T.
\]


The final endpoint retains the particle integral equation, the exact iid initial law and the actual Brownian input alongside this bound. The Wasserstein distance is proved finite before converting it to a real number. This proves convergence of actual tagged one-time laws; pathwise strong-SDE, expected path-supremum and gradient-flow PDE statements remain outside the established result.



The named particle input is the copied latent-only Brownian input plus the separately scaled parameter Brownian input. The final existential theorem retains that exact input and the actual empirical-gradient integral equation, while the tagged coupling converts the previously proved coordinate estimate to the displayed law bound for every \(N\), tag and time.





Insert the constructed coordinate error bound into the explicit coupling estimate at each fixed time. This proves finite \(W_2\) and the rate \(C_T/\sqrt N\) uniformly over the specified time interval and tag. The conclusion retains the empirical-gradient integral equation, copied iid initialization and actual Brownian input, so it refers to those processes rather than an arbitrary family of nearby probability laws.
