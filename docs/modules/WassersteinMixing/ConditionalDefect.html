The actual Langevin dynamics, reversible semigroup, corrector, Gaussian ULA invariant law and comparison estimates are constructed. The actual Hilbert conditional-expectation projection commutes with Bochner time integration. If each increment has conditional mean equal to an evaluated source, the time-integrated defect has conditional mean equal to the evaluated integrated source.

Mathematical statement and proof

Claim. If E[I(t)∣F]=Us(t)\mathbb E[I(t)\mid\mathcal F]=U s(t)E[I(t)∣F]=Us(t) for 0≤t≤h0\le t\le h0≤t≤h, where UUU is an evaluation isometry and the increment curve is integrable, then

E[∫0hI(t) dt | F]=U(∫0hs(t) dt).\mathbb E\left[\int_0^h I(t)\,dt\,\middle|\,\mathcal F\right]=U\left(\int_0^h s(t)\,dt\right).E[∫0h​I(t)dt​F]=U(∫0h​s(t)dt).

Proof. Express conditional expectation as the orthogonal projection onto the closed past-measurable L2L^2L2 subspace. It is bounded linear, so it commutes with the justified integral. Substitute the pointwise conditional-mean identities inside the integral. Evaluation is also bounded linear and commutes with the same integral, yielding the displayed result.

How the Lean proof follows this argument

conditionalDefect_eq_evaluation_integral uses the actual lpMeas orthogonal projection and its interval-integral commutation theorem, then the evaluation isometry integral identity. Pointwise substitution is justified on the full closed time interval.
