Statement and proof

01The real part of the actual compression pairing §

Mathematical statement and proof

Claim. The actual complex operator, viewed as a real linear map, equals the actual real operator on the same complex-valued observable space.

Proof. Test the two outputs against any observable using the real inner product. The real L2L^2L2 pairing equals the real part of its complex pairing. Apply the actual complex compression identity, then return to the real pairing of the actual evaluations. Their pointwise pullbacks are identical over both scalar fields. The actual real compression identity now gives exactly the second operator pairing. Separation by all real inner-product tests proves equality.

How the Lean proof follows this argument

op_restrictScalars uses real_inner_Lp_eq_re and both scalar versions of compression_inner. The proof compares the actual evaluation maps; it does not postulate equality of the two transitions.
