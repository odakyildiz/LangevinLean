The actual Brownian and independent-uniform MALA source

References and publication status for this development

Preprint source; original statements proved by a modified argument

The supplied manuscript is audited by exact source hashes and compared with arXiv:2608.02430v1. Theorem 1 and Corollary 1.1 are proved under their original C2C^2C2 Hessian assumptions, with the same constants, using a modified proof. The actual Langevin dynamics, reversible semigroup, corrector, Gaussian ULA invariant law and comparison estimates are constructed. The paper's generator/eigenbasis construction and Gaussian-smoothing passage are not formalized. The separate IPLA application derives new bounds by combining this result with Project 03's particle geometry and parameter concentration.

  • Francesco Pedrotti and Peter A. Whalley (2026). Wasserstein mixing time of the unadjusted Langevin algorithm. arXiv preprint arXiv:2608.02430, version 1 (3 August 2026). Paper HTML · Full paper

Adjoin an independent infinite uniform path to the actual Gibbs/Brownian probability space. Its normalized Brownian innovations and uniform decisions have the required product path law, so the deterministic common-randomness recursion realizes the actual coupled Euler/MALA laws.

01The genuine augmented source and Gaussian path law §

Mathematical statement and proof

Construction. Take the product of the actual Gibbs/Brownian source with independent uniforms (Un)n(U_n)_n(Un​)n​. The Brownian innovations at step r>0r>0r>0 have the standard Gaussian infinite-product law and are independent of the actual initial state.

Proof. Coordinate Brownian increments are independent centered Gaussians with the exact interval variance. Their prescribed normalization gives standard Gaussian vectors. The initial Gibbs factor was independent of the Brownian source. The actual product extension retains both these laws and adds only independent uniform decisions.

Earlier results used here: ULA-SC, Section 3.17.2; ULA-SC, Section 3.22.21; ULA-SC, Section 3.23.5; ULA-SC, Section 3.26.3; ULA-SC, Section 3.32.14; ULA-SC, Section 3.32.15; ULA-SC, Section 3.32.16; ULA-SC, Section 3.32.5; ULA-SC, Section 3.41.1; ULA-SC, Section 3.45.3; ULA-SC, Section 3.8.17; ULA-SC, Section 3.8.19; ULA-SC, Section 3.8.20; ULA-SC, Section 3.8.22.

02The exact canonical sampled recursion law §

Mathematical statement and proof

Claim. The augmented initial/innovation input has the product law of the diagonal Gibbs initialization and independent Gaussian/uniform pairs. The canonical recursion therefore has exactly the actual coupled Euler/MALA finite-time law.

Proof. Zip the actual Gaussian path with the independent uniform path using the proved infinite-product identity. Apply the deterministic sampled-chain pushforward theorem to this exact input law. The one-step sampled law has already been identified with the actual coupled Gaussian Metropolis step.

Earlier results used here: ULA-SC, Section 3.20.1; ULA-SC, Section 3.20.4; ULA-SC, Section 3.20.5; ULA-SC, Section 3.26.3; ULA-SC, Section 3.36.14.

How the Lean proof follows this argument

input_law uses augment_initial_noise_law. state applies the genuine paired recursion to this input; state_law uses its exact deterministic-to-Markov law theorem and chainLaw_eq_coupledChain.
