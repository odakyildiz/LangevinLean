Mathematical statement and proof

Construction. Given the Poisson process identified with the actual Brownian filtration and grid evaluations, use the actual stationary diffusion reference, its synchronous Euler chain, the true gradient increments and the actual random segment Hessian.

Proof. Gibbs stationarity and the true Gaussian iteration theorem give the actual target and chain laws. The score moment, compact-time integrability, increment constant, endpoint identity and exact conditional defect mean supply the local estimates. The actual synchronous recursion and averaged-Hessian secant identity give the exact error equation. Actual past adaptation and true curvature symmetry and form bounds supply the predictable geometry. The physical dimension equality is exact. Thus every comparison field is derived from actual objects; no shifted-energy, bias or transport conclusion is supplied as input.

Earlier results used here: ULA-SC, Section 3.26.3.

How the Lean proof follows this argument

comparisonFromActualProcess fills ULAPoissonComparison using actualObservableScore_energy, the actual local-defect facts, actual_curvature_error_step, actual adaptation and the true curvature theorems. It transports only the exact filtration/evaluation/source identifications required by the supplied actual process.
