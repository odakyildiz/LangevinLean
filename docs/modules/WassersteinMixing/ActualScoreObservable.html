01Constructing the square-integrable gradient §

Mathematical statement and proof

Claim. ∇V∈L2(π)\nabla V\in L^2(\pi)∇V∈L2(π), where π\piπ is the normalized Gibbs law of the actual potential.

Proof. Strong convexity makes the Gibbs partition function finite. The shared Gibbs gradient-moment theorem then proves square integrability of the Lipschitz gradient. Passing to its equivalence class preserves the actual gradient as an almost-everywhere representative.

Earlier results used here: ULA-SC, Section 3.26.10; ULA-SC, Section 3.26.3; ULA-SC, Section 3.27.7.

How the Lean proof follows this argument

actual_gradient_memLp specializes the Gibbs moment theorem with the actual potential constants. actualObservableScore uses the resulting toLp constructor and actualObservableScore_coe records its precise representative.

02Evaluating the actual score without a new identification hypothesis §

Mathematical statement and proof

Claim. The stationary evaluation map Unf=f(Ynh)U_n f=f(Y_{nh})Un​f=f(Ynh​) is an isometry, agrees with global evaluation at nhnhnh, and satisfies Unf=∇V(Ynh)U_nf=\nabla V(Y_{nh})Un​f=∇V(Ynh​). Consequently ∥f∥L2(π)2≤βd\|f\|_{L^2(\pi)}^2\le\beta d∥f∥L2(π)2​≤βd.

Proof. The actual grid state has law π\piπ, giving the isometry. The proved global/grid path identity identifies the two evaluation maps. Pull the gradient representative through this measure-preserving state map to identify its evaluated class with the actual drift class. Apply the actual score moment at one time and use the isometry.

Earlier results used here: ULA-SC, Section 3.13.3; ULA-SC, Section 3.26.3.

How the Lean proof follows this argument

actualGridEvaluation_score transports the almost-everywhere target representative through the actual stationary map and compares it with lpDrift_coe. actualObservableScore_energy transfers the actual probability-space moment through the evaluation isometry.
