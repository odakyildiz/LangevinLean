A finite Euler endpoint as a measurable function of actual inputs

References and publication status for this development

Preprint source; original statements proved by a modified argument

The supplied manuscript is audited by exact source hashes and compared with arXiv:2608.02430v1. Theorem 1 and Corollary 1.1 are proved under their original C2C^2C2 Hessian assumptions, with the same constants, using a modified proof. The actual Langevin dynamics, reversible semigroup, corrector, Gaussian ULA invariant law and comparison estimates are constructed. The paper's generator/eigenbasis construction and Gaussian-smoothing passage are not formalized. The separate IPLA application derives new bounds by combining this result with Project 03's particle geometry and parameter concentration.

  • Francesco Pedrotti and Peter A. Whalley (2026). Wasserstein mixing time of the unadjusted Langevin algorithm. arXiv preprint arXiv:2608.02430, version 1 (3 August 2026). Paper HTML · Full paper

A finite Euler endpoint is a measurable function of its starting state and the whole future coordinate path. This exact pointwise description links the actual L2L^2L2 recursion to whole-path independence and conditional averaging.

Statement and proof

01The actual pointwise recursion and its representative §

Mathematical statement and proof

Construction. Starting from xxx and a future path www, recursively add the true gradient Euler drift and consecutive increments of 2w\sqrt2w2​w. The resulting endpoint map is measurable.

Claim and proof. The actual shifted Euler L2L^2L2 variable equals this map applied to (Ya,Wa)(Y_a,W_a)(Ya​,Wa​) almost surely. The actual Brownian increment has the explicit raw future-coordinate representative. Induction on the Euler recursion combines this identity with the almost-everywhere true gradient representative and the preceding endpoint representative. Thus only actual state and future-path evaluations occur.

Earlier results used here: ULA-SC, Section 3.13.2; ULA-SC, Section 3.13.3; ULA-SC, Section 3.16.1; ULA-SC, Section 3.24.14; ULA-SC, Section 3.24.15; ULA-SC, Section 3.24.21; ULA-SC, Section 3.25.1.

How the Lean proof follows this argument

pointwiseEulerMap_measurable inducts through the true measurable proposal update. shiftedNoise_coe identifies the actual additive Brownian increment. shiftedEuler_coe proves equality of the actual recursion and measurable input map by almost-everywhere induction.
