Mathematical statement and proof

Claim. For every real target observable fff, the actual process source is

(I−Ph)Ghf=∫0h(f−Psf) ds.(I-P_h)G_hf=\int_0^h(f-P_sf)\,ds.(I−Ph​)Gh​f=∫0h​(f−Ps​f)ds.

For the actual gradient observable, its evaluated value equals the conditional mean of the genuine local defect. Thus the actual reference and Euler chain form the complete stationary Poisson comparison.

Proof. The semigroup corrector theorem gives the integral source for the extracted real operator. That operator is already identified with the actual real Langevin transition, so the integrands agree. The independently proved conditional defect-mean formula has precisely this integral. Substitute the source identity to obtain the exact comparison mean. The concrete comparison constructor then fills every remaining field from the proved actual scores, increments, curvature, adaptation and laws.

Earlier results used here: ULA-SC, Section 3.26.3.

How the Lean proof follows this argument

actualPoissonSource_eq_integral rewrites the general real corrector source using actualRealOp_eq_op. actualPoissonProcess_defect_mean matches the independently proved actual defect mean. actualULAComparison invokes the concrete constructor with definitional filtration/evaluation identities and this proved mean, adding no realization assumption.
