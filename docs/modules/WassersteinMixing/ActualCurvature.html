References and publication status for this development

Preprint source; original statements proved by a modified argument

The supplied manuscript is audited by exact source hashes and compared with arXiv:2608.02430v1. Theorem 1 and Corollary 1.1 are proved under their original C2C^2C2 Hessian assumptions, with the same constants, using a modified proof. The actual Langevin dynamics, reversible semigroup, corrector, Gaussian ULA invariant law and comparison estimates are constructed. The paper's generator/eigenbasis construction and Gaussian-smoothing passage are not formalized. The separate IPLA application derives new bounds by combining this result with Project 03's particle geometry and parameter concentration.

01Identifying the true error operator §

Mathematical statement and proof

Claim. With An(ω)=A‾(Ynh(ω),Xn(ω))A_n(\omega)=\overline A(Y_{nh}(\omega),X_n(\omega))An​(ω)=A(Ynh​(ω),Xn​(ω)), the exact error recursion is

en+1=en−hAnen+Dn.e_{n+1}=e_n-hA_ne_n+D_n.en+1​=en​−hAn​en​+Dn​.

Proof. The actual random-curvature construction gives a bounded operator on the common L2L^2L2 space. Its secant identity is precisely Anen=∇V(Ynh)−∇V(Xn)A_ne_n=\nabla V(Y_{nh})-\nabla V(X_n)An​en​=∇V(Ynh​)−∇V(Xn​). Substitution into the previously derived synchronous update gives the displayed equality.

Earlier results used here: ULA-SC, Section 3.13.2.

How the Lean proof follows this argument

actualCurvature specializes randomCurvature to the actual two states. actual_curvature_error_step rewrites the genuine gradient difference using randomCurvature_secant.

02Curvature and measurable-past properties §

Mathematical statement and proof

Claim. The actual operator is symmetric, α∥U∥22≤⟨U,AnU⟩≤β∥U∥22\alpha\|U\|_2^2\le\langle U,A_nU\rangle\le\beta\|U\|_2^2α∥U∥22​≤⟨U,An​U⟩≤β∥U∥22​, and it preserves measurability with respect to any sub-sigma-algebra that contains both current states.

Proof. These are the integrated properties of the true averaged Hessian. For adaptation, the field depends continuously on the two current states; evaluating it on a measurable vector therefore remains measurable with respect to the same information.

How the Lean proof follows this argument

The symmetry and form estimates specialize the proved random-curvature theorems. actualCurvature_adapted applies their sub-sigma-algebra measurability result to the actual reference and chain.
