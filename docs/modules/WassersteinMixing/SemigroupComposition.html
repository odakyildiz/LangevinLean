The semigroup law from the actual conditional Markov identity

References and publication status for this development

Preprint source; original statements proved by a modified argument

The supplied manuscript is audited by exact source hashes and compared with arXiv:2608.02430v1. Theorem 1 and Corollary 1.1 are proved under their original C2C^2C2 Hessian assumptions, with the same constants, using a modified proof. The actual Langevin dynamics, reversible semigroup, corrector, Gaussian ULA invariant law and comparison estimates are constructed. The paper's generator/eigenbasis construction and Gaussian-smoothing passage are not formalized. The separate IPLA application derives new bounds by combining this result with Project 03's particle geometry and parameter concentration.

The conditional Markov identity on the actual initial/Brownian past implies the composition law for the canonical real observable contractions. Its proof uses actual adaptedness of time-zero evaluation and the defining adjoint pairings.

Statement and proof

01Conditioning the actual two-time pairing §

Mathematical statement and proof

Claim. If E[Ua+tf∣Fa]=UaPtf\mathbb E[U_{a+t}f\mid\mathcal F_a]=U_aP_tfE[Ua+t​f∣Fa​]=Ua​Pt​f, then Pa+t=PaPtP_{a+t}=P_aP_tPa+t​=Pa​Pt​.

Proof. Time-zero evaluation is measurable with respect to the actual past because that past contains the initialization. Pair the conditional identity with U0gU_0gU0​g. The conditional-expectation projection preserves its pairing with this adapted vector. The adjoint compression identities identify the resulting sides with ⟨Pa+tf,g⟩\langle P_{a+t}f,g\rangle⟨Pa+t​f,g⟩ and ⟨PaPtf,g⟩\langle P_aP_tf,g\rangle⟨Pa​Pt​f,g⟩. Equality against all test observables proves the operator identity.

Earlier results used here: ULA-SC, Section 3.26.3; ULA-SC, Section 3.54.4; ULA-SC, Section 3.54.5; ULA-SC, Section 3.54.6.

How the Lean proof follows this argument

evaluation_zero_adapted_pastAt uses the actual initial-state generator of the past. op_add_of_markov applies the real conditional-expectation pairing theorem and the exact evaluation compression identities, then uses inner-product extensionality.
