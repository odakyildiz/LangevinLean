References and publication status for this development

Published source; corrected checked proofs

The comparison uses the supplied mainDR_dec_18.tex manuscript. The results prove Wasserstein convergence of the kinetic diffusion, invariance of its Gibbs measure, KLMC and KLMC2 error estimates for correlated Gaussian increments, their Cholesky representations, and explicit iteration counts for a prescribed error. The corrected proofs are unpublished. The reference table records the correction to the continuous prefactor and the stochastic Hessian-difference terms retained in the second-order comparison. The KLMC2 estimate retains the exact fourth Gaussian moment in every dimension; the coarser displayed simplification assumes p≥2. The stronger inverse-step-square exponential term is also proved. Continuous solutions are continuous in L² on finite time intervals. Almost-sure continuity of sample paths is not proved here.

  • Arnak S. Dalalyan and Lionel Riou-Durand (2020). On sampling from a log-concave density using kinetic Langevin diffusions. Bernoulli 26(3), 1956–1988. arXiv

The local KLMC analysis compares a numerical state with an exact reference state. On each step it inserts an auxiliary exact path started at the numerical state and driven by precisely the same additive input as the reference. This section constructs those paths from the proved kinetic flow. The differential, kinematic and mild identities used in the local-error theorem follow from their integral equations.

The exact reference, numerical chain, and auxiliary exact path have different initial phases but compatible local inputs. Their proved integral identities provide the complete structural foundation of the coupling argument.

02Use a raw continuous input with the selected kinetic flow §

Mathematical statement and proof

A continuous input WWW is restricted to the compact solution horizon, giving a continuous function on that compact interval. If W0=0W_0=0W0​=0, the flow's normalized clipped extension equals WtW_tWt​ at every time in that horizon. The interval projection fixes every point in the solution horizon, so clipping does not change the input there. The selected segment is then the kinetic solution map given by Picard existence with that compact input. Its specification gives continuity, its initial condition, and the exact integral equation with the original raw input.

The selected flow only needs a continuous additive velocity input starting at zero. Subtracting the input’s initial value supplies that normalization for a raw continuous path. This permits local segments to be defined uniformly without choosing a new stochastic solution for each interval.

03Derive velocity, kinematic and mild equations by projection §

Mathematical statement and proof

Applying the velocity continuous linear projection to the kinetic integral equation gives Vt−V0=−∫0t(γVs+ug(Xs))ds+WtV_t-V_0=-\int_0^t(\gamma V_s+u g(X_s))ds+W_tVt​−V0​=−∫0t​(γVs​+ug(Xs​))ds+Wt​. Applying the position projection gives Xt−X0=∫0tVsdsX_t-X_0=\int_0^tV_sdsXt​−X0​=∫0t​Vs​ds, because the positional input is exactly zero. In both cases the continuous linear projection commutes with the Bochner integral. If the filtered input satisfies Bt=Wt−γ∫0tBsdsB_t=W_t-\gamma\int_0^tB_sdsBt​=Wt​−γ∫0t​Bs​ds, the proved Banach-space integrating-factor theorem gives VT=ψ0(T)V0−∫0Te−γ(T−s)ug(Xs)ds+BTV_T=\psi_0(T)V_0-\int_0^Te^{-\gamma(T-s)}u g(X_s)ds+B_TVT​=ψ0​(T)V0​−∫0T​e−γ(T−s)ug(Xs​)ds+BT​. Thus the exponential mild equation is a consequence of the kinetic equation, rather than a new stochastic hypothesis.

Projection of the phase equation gives the velocity and position integral identities. The integrating-factor argument then gives the mild velocity formula, while the position equation is already the kinematic primitive. These are the exact analytic identities required by the local-error estimate.

04Construct exact reference segments and the defined numerical chain §

Mathematical statement and proof

The reference chain starts from its supplied phase vector. At each iteration, its next state is the endpoint of the selected exact kinetic segment driven by that iteration's input. The corresponding reference segment is the same selected path, so its endpoint matches the next reference state by definition. The numerical chain instead performs the frozen-force exponential update with innovation (Bn(h),∫0hBn(s)ds)(B_n(h),\int_0^hB_n(s)ds)(Bn​(h),∫0h​Bn​(s)ds). This uses the constructed filtered input and its positional primitive.

The reference uses exact selected segments; the numerical sequence uses the defined exponential update with the same interval responses. Their endpoint matching is built into the recursions. The comparison is therefore between trajectories rather than arbitrary sequences satisfying a desired bound.

05The auxiliary exact path from the current numerical state §

Mathematical statement and proof

The auxiliary segment is a selected exact kinetic solution whose initial condition is the current exponential-integrator state. It receives exactly the same raw Brownian input as the reference segment on that iteration. The two specification theorems prove continuity, exact starting values, reference endpoint matching, and their shared-input integral equations. All these properties follow from the kinetic integral equation; no contraction or local-error inequality is inserted into the definitions.

At step nnn, start an auxiliary exact segment at the numerical phase and drive it by the same input as the reference segment. It agrees initially with the numerical state, enabling the freezing-error estimate. Its discrepancy from the reference is controlled by exact-flow contraction.

06Discharge the local-error proof's kinematic and mild requirements §

Mathematical statement and proof

The constructed auxiliary path has its positional primitive identity by the general kinetic projection theorem. Its exponentially weighted force formula follows by restricting its integral equation to any smaller time t≤ht\le ht≤h, restricting the filtered-input balance to the same interval, and applying the generic mild theorem. The argument explicitly checks the interval inclusions and simplifies the inverse mass u=1u=1u=1. The remaining stochastic work concerns the law and stationarity of the reference; the coupling segments and their integral identities have been constructed.

The local-error argument needs continuity, the mild equation, and the integrated-velocity position equation. Each follows from the selected solution’s specification. These hypotheses are therefore verified when the constructed segments are inserted into the one-step coupling theorem.
