A global kinetic reference for the local coupling trajectories

References and publication status for this development

Published source; corrected checked proofs

The comparison uses the supplied mainDR_dec_18.tex manuscript. The results prove Wasserstein convergence of the kinetic diffusion, invariance of its Gibbs measure, KLMC and KLMC2 error estimates for correlated Gaussian increments, their Cholesky representations, and explicit iteration counts for a prescribed error. The corrected proofs are unpublished. The reference table records the correction to the continuous prefactor and the stochastic Hessian-difference terms retained in the second-order comparison. The KLMC2 estimate retains the exact fourth Gaussian moment in every dimension; the coarser displayed simplification assumes p≥2p\ge2p≥2. The stronger inverse-step-square exponential term is also proved. Continuous solutions are continuous in L2L^2L2 on finite time intervals. Almost-sure continuity of sample paths is not proved here.

  • Arnak S. Dalalyan and Lionel Riou-Durand (2020). On sampling from a log-concave density using kinetic Langevin diffusions. Bernoulli 26(3), 1956–1988. arXiv

The exact reference segments are constructed on one specified Brownian source. This section identifies their increment input with the increments of one full L2L^{2}L2 Brownian input and proves that every stitched reference state and intermediate segment point belongs to the full kinetic solution.

The constructed local inputs are increments of one global Brownian input. A global kinetic solution and uniqueness then identify every stitched reference state and segment used by the sampler coupling.

01The constructed input and its increments §

Mathematical statement and proof

The full input is the scalar specified Brownian value assembled spatially and pulled onto the initial-coupling extension with amplitude 2γ\sqrt{2\gamma}2γ​. It is continuous in L2L^{2}L2 because each assembly and pullback is continuous linear. The Brownian value at zero vanishes because that its deterministic time indicator has empty support and the isonormal map is linear. For nonnegative local time, the constructed segment input equals the full input difference at nh+tnh+tnh+t and nhnhnh. For nonnegative local times, linearity of spatial assembly and source pullback preserves this increment identity.

The full constructed input is a continuous Hilbert-space Brownian path with zero initial value. Its local increments agree with the already constructed interval inputs. This consistency permits independently defined local solution segments to be compared with one global solution.

Earlier results used here: ULA-SC, Section 3.17.1; ULA-SC, Section 3.8.2; ULA-SC, Section 3.8.9.

02The full reference solution §

Mathematical statement and proof

The global reference is the selected kinetic solution with the lifted gradient, the constructed reference initial phase and the full specified Brownian input. Its specification proves continuity, its exact starting phase, and the kinetic integral equation over the whole finite horizon. There is no stationary-law requirement in its definition.

The global reference is the selected kinetic solution over the complete horizon, initialized at the Gibbs phase. Its definition requires only the drift and forcing, while stationarity is proved afterward. The construction therefore avoids using invariance as an existence assumption.

Earlier results used here: ULA-SC, Section 3.13.2; ULA-SC, Section 3.13.5; ULA-SC, Section 3.17.1.

03Identify every stitched reference point by uniqueness §

Mathematical statement and proof

The generic stitching theorem now applies because the local inputs are proved to be increments of the full input. Consequently Rn=YnhR_n=Y_{nh}Rn​=Ynh​, and Zn(t)=Ynh+tZ_n(t)=Y_{nh+t}Zn​(t)=Ynh+t​ throughout each step whose endpoint lies in the global horizon. The argument instantiates the existing exact uniqueness results with the L2L^{2}L2 gradient and checks the horizon arithmetic. Thus a stationary law for the full constructed kinetic solution supplies the law of all reference states used by the quantitative KLMC proof.

Uniqueness identifies each shifted global path with the corresponding selected local segment. Induction identifies all grid endpoints, and the same argument identifies intermediate times. Hence the local coupling proof can use global stationary laws throughout each step.

Earlier results used here: ULA-SC, Section 3.13.2; ULA-SC, Section 3.13.5; ULA-SC, Section 3.17.1.
