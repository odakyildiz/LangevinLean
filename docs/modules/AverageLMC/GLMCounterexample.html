A Gaussian-design counterexample using the actual potential Hessian

References and publication status for this development

Supplied manuscript; checked sampling proofs and separate source mistakes

The exact supplied manuscript is the correspondence authority. Its main average-smoothness LMC, decreasing-step, Laplacian-smooth LMC and fixed-point control-variate SGLD statements are proved for actual Gaussian sampling laws with the source constants. Extended transport endpoints cover arbitrary probability initializations. The Laplacian proof uses exactly C3 regularity and the gradient-of-Laplacian condition. Verified counterexamples to the false Gaussian-design proposition, its empirical fourth-moment event and an intermediate SGLD transient comparison have separate pages linked from the top of the overview. The complete source inventory distinguishes this main-theorem review scope from broader auxiliary statements not reproduced in full standalone generality; literal full-paper proof coverage is not claimed.

  • Arnak S. Dalalyan and Avetik Karagulyan (undated manuscript). Improved Guarantees for Langevin Monte Carlo with Average Smoothness. Supplied Arxiv_version_May_26.tex; publication status not established.

This module combines the genuine finite-sum GLM potential and the Gaussian probability obstruction. The design has n=p independent standard Gaussian rows, exactly the isotropic case allowed by the source. The bound event uses the derivative of the actual gradient of the actual potential, so no Hessian identification or concentration estimate is assumed.

Statement and proof

01Construct precisely the square isotropic Gaussian design §

Mathematical statement and proof

GaussianDesign p stores p vectors in Rp\mathbb R^pRp. Its measure is the finite product of p standard Gaussian laws. The product is a probability measure; evaluation at any row preserves the standard Gaussian law, and the coordinate evaluation maps are independent. These facts establish the design assumptions for the counterexample.

02Translate the table into an actual Hessian event §

Mathematical statement and proof

The isotropic table asserts M2p≤CnpM_2\sqrt p\le Cn\sqrt pM2​p​≤Cnp​, so at n=p it requires the actual Hessian to be Lipschitz with bound Cp. glmHessianBoundEvent expresses exactly that inequality for all states using fderiv of the actual gradient. The proved rank-one lower bound forces every design in this event to satisfy ∥Xi∥3≤Cp\|X_i\|^3\le Cp∥Xi​∥3≤Cp. The row law transfers this event probability to the standard Gaussian measure. For p>16p>16p>16 and p>8C2p>8C^2p>8C2, the probability is strictly below one half.

03Rule out every dimension independent table constant §

Mathematical statement and proof

Assume one nonnegative constant C makes the Hessian bound event have probability at least one half for every positive dimension. Choose a natural p above both 16 and 8C28C^28C2; the previous theorem gives probability below one half for its first row, a contradiction. The component derivative bound is always the fixed value four, so allowing C to depend only on that bound does not remove the contradiction. The main sampler convergence proofs are independent of this false Gaussian design claim.
