01Finitely many values of a Gaussian linear map are jointly Gaussian §

Mathematical statement and proof

Recall that a probability measure on R\mathbb RR is Gaussian if it equals N(m,v)\mathcal N(m,v)N(m,v) for some m∈Rm\in\mathbb Rm∈R and v≥0v\ge0v≥0, where N(m,0)\mathcal N(m,0)N(m,0) is the Dirac mass at mmm. For a finite set ι\iotaι, a probability measure μ\muμ on Rι\mathbb R^\iotaRι is Gaussian if for every linear functional L:Rι→RL:\mathbb R^\iota\to\mathbb RL:Rι→R the image measure L#μL_\#\muL#​μ, defined by L#μ(A)=μ(L−1(A))L_\#\mu(A)=\mu(L^{-1}(A))L#​μ(A)=μ(L−1(A)), is a Gaussian law on R\mathbb RR. A random vector V:Ω→RιV:\Omega\to\mathbb R^\iotaV:Ω→Rι has a Gaussian law under PPP if it is measurable up to a PPP-null set and its law V#PV_\#PV#​P is Gaussian. For ι\iotaι with one element this is the notion for real random variables, since every linear functional on R\mathbb RR is y↦cyy\mapsto cyy↦cy and the image of N(m,v)\mathcal N(m,v)N(m,v) under it is N(cm,c2v)\mathcal N(cm,c^2v)N(cm,c2v).

Claim. Let (Ω,F,P)(\Omega,\mathcal F,P)(Ω,F,P) be a measure space, let HHH be a real vector space and let T:H→L2(P)T:H\to L^2(P)T:H→L2(P) be a linear map such that, for every x∈Hx\in Hx∈H, the real random variable T(x)T(x)T(x) has a Gaussian law under PPP. Let ι\iotaι be a finite set and let (fi)i∈ι(f_i)_{i\in\iota}(fi​)i∈ι​ be vectors of HHH. Then the random vector

How the Lean proof follows this argument

The variables [AddCommMonoid H] [Module ℝ H] make H a real vector space without any topology, P : Measure Ω is an arbitrary measure, and [Finite ι] says that the index type is finite. T : H →ₗ[ℝ] Lp ℝ 2 P is an R\mathbb RR-linear map into L2(P)L^2(P)L2(P), hT is the hypothesis that every value has a Gaussian law, and the conclusion concerns the map fun ω (i : ι) ↦ T (f i) ω with values in the function type ι → ℝ, that is Rι\mathbb R^\iotaRι. Mathlib's HasGaussianLaw consists of almost-everywhere measurability of the random variable and the statement that its law is Gaussian (IsGaussian): for every continuous linear functional LLL, the image of the law under LLL is the real Gaussian law with the mean and variance of that image. On Rι\mathbb R^\iotaRι with ι\iotaι finite, every linear functional is continuous.

  1. letI := Fintype.ofFinite ι chooses an enumeration of the finite type, so that sums over all of ι can be written.
  2. hmeas is the measurability part: aemeasurable_pi_iff.mpr reduces it to the coordinates, each of which is almost everywhere measurable by Lp.aestronglyMeasurable (T (f i)).
  3. refine ⟨hmeas, isGaussian_of_isGaussian_map fun L ↦ ?_⟩ supplies the two fields of HasGaussianLaw. Mathlib's isGaussian_of_isGaussian_map reduces IsGaussian of the law to showing that its image under each continuous linear functional L is a Gaussian measure on R\mathbb RR, which is the definition used in the claim.
  4. c is the coefficient vector ci=L(ei)c_i=L(e_i)ci​=L(ei​), the unit vector being written fun j ↦ if i = j then 1 else 0. hL is (1), obtained from LinearMap.pi_apply_eq_sum_univ applied to the underlying linear map L.toLinearMap, with mul_comm to order the factors.
  5. hsum is (2), proved by simp only [map_sum, map_smul].
  6. hprojection is (3). hscalar collects the almost-everywhere identities Lp.coeFn_smul for scalar multiples for all i at once, using ae_all_iff (countably many, here finitely many, almost-everywhere statements hold simultaneously almost everywhere). Lp.coeFn_fun_finsetSum gives the representative of a finite sum, and after filter_upwards the rewrites with hcoe and hL and the termwise identity hsmul finish.
  7. hprojectedGaussian is the Gaussian law of L∘VL\circ VL∘V: (hT (∑ i, c i • f i)).congr hprojection transfers the hypothesis along (3).
  8. The final rw [AEMeasurable.map_map_of_aemeasurable …] is the identity L#(V#P)=(L∘V)#PL_\#(V_\#P)=(L\circ V)_\#PL#​(V#​P)=(L∘V)#​P of the conclusion; its measurability hypotheses are the measurability of the continuous map L (L.continuous.measurable.aemeasurable) and hmeas. The goal is then the field hprojectedGaussian.isGaussian_map.

02A Gaussian process from a Gaussian linear map §

Mathematical statement and proof

A family (Xt)t∈Θ(X_t)_{t\in\Theta}(Xt​)t∈Θ​ of real random variables, indexed by an arbitrary set Θ\ThetaΘ, is a Gaussian process under PPP if for every finite set J⊆ΘJ\subseteq\ThetaJ⊆Θ the random vector (Xt)t∈J(X_t)_{t\in J}(Xt​)t∈J​ has a Gaussian law on RJ\mathbb R^JRJ.

Claim. Let PPP, HHH and TTT be as in the previous step: T:H→L2(P)T:H\to L^2(P)T:H→L2(P) is linear and every T(x)T(x)T(x) has a Gaussian law. Let Θ\ThetaΘ be an arbitrary set and let f:Θ→Hf:\Theta\to Hf:Θ→H be any map. Then the process Xt=T(f(t))X_t=T(f(t))Xt​=T(f(t)), t∈Θt\in\Thetat∈Θ, formed with representatives of the classes T(f(t))T(f(t))T(f(t)), is a Gaussian process under PPP.

Proof. Let J⊆ΘJ\subseteq\ThetaJ⊆Θ be finite. The previous step, applied with the finite index set ι=J\iota=Jι=J and the vectors ft=f(t)f_t=f(t)ft​=f(t) for t∈Jt\in Jt∈J, shows that (Xt)t∈J=(T(f(t)))t∈J(X_t)_{t\in J}=(T(f(t)))_{t\in J}(Xt​)t∈J​=(T(f(t)))t∈J​ has a Gaussian law on RJ\mathbb R^JRJ. □\square□

The set Θ\ThetaΘ and the map fff are arbitrary; in particular Θ\ThetaΘ may be uncountable. The claim concerns finite-dimensional distributions only: it asserts no measurability or continuity of the paths t↦Xt(ω)t\mapsto X_t(\omega)t↦Xt​(ω).

How the Lean proof follows this argument

Mathlib's IsGaussianProcess X P is a structure with a single field hasGaussianLaw: for every finite set I : Finset T of indices, the vector fun ω ↦ I.restrict (X · ω) of values at the indices in I has a Gaussian law. Here the index type is Time, an arbitrary type. The proof supplies this field with hasGaussianLaw I := hasGaussianLaw_pi_of_linearMap_Lp P T hT (fun i : I ↦ f i): the elements of the finite set I form a finite type, and the restricted vector is by definition the vector of the previous step for the family fun i : I ↦ f i.
