01The recursion on square-integrable random variables §

Mathematical statement and proof

For an initial X0∈L2(P;H)X_0\in L^2(P;H)X0​∈L2(P;H) and innovations ξk∈L2(P;H)\xi_k\in L^2(P;H)ξk​∈L2(P;H), set Xk+1=Xk−h∇U^(Xk)+2h ξkX_{k+1}=X_k-h\widehat{\nabla U}(X_k)+\sqrt{2h}\,\xi_kXk+1​=Xk​−h∇U(Xk​)+2h​ξk​.

The initial iterate is the supplied random vector.

Each successor uses the Euler update using the given gradient.

The drift lift evaluates the original gradient almost everywhere, so this recursion represents the ordinary ULA method on random inputs. The reference equation and defect integral are Bochner equations in this same Hilbert space. Each step stays square-integrable by the Lipschitz growth estimate for the gradient.

02The successor update §

Mathematical statement and proof

The next iterate is exactly one L² ULA update of the current iterate.

Evaluate the successor clause of the definition.

The successor step uses the innovation at the same index as the reference endpoint. Subtracting a reference equation using that same innovation removes the stochastic increment exactly. The resulting error equation therefore contains only the deterministic Euler difference and the local defect.

For 0≤t≤h0\le t\le h0≤t≤h, require

Yk,t−Yk,0=−∫0tg(Yk,s) ds+Bk,t.Y_{k,t}-Y_{k,0}=-\int_0^t g(Y_{k,s})\,ds+B_{k,t}.Yk,t​−Yk,0​=−∫0t​g(Yk,s​)ds+Bk,t​.

The segment-joining condition makes the local initial point of segment k+1k+1k+1 equal to the endpoint of segment kkk. The stationary grid-law condition identifies each comparison marginal with π\piπ, while the endpoint-noise condition identifies the reference's final increment with the algorithm innovation. The two moment assumptions have different roles: drift controls the deterministic segment increment, and noise controls its square-root growth.

04Convergence from the supplied integral reference §

Mathematical statement and proof

Suppose a reference with the preceding properties is supplied, h≥0h\ge0h≥0, and Lh≤2Lh\le2Lh≤2. Let 0≤q<10\le q<10≤q<1, and assume the lifted Euler map contracts:

Apply the Euler-defect identity at t=ht=ht=h, then substitute the segment join and endpoint noise identities. This proves the claimed reference update. Its defect has a minus sign.

Fix kkk and compare the numerical update with the reference endpoint equation, both using the same ξk\xi_kξk​.

Cancel their identical noise terms. Because the reference subtracts DkD_kDk​,

Xk+1−Yk+1,0=(Xk−hg(Xk))−(Yk,0−hg(Yk,0))+Dk.X_{k+1}-Y_{k+1,0}=\bigl(X_k-hg(X_k)\bigr)-\bigl(Y_{k,0}-hg(Y_{k,0})\bigr)+D_k.Xk+1​−Yk+1,0​=(Xk​−hg(Xk​))−(Yk,0​−hg(Yk,0​))+Dk​.

The joint law of the pair supplies a finite-cost coupling, so its transport distance is at most ene_nen​. The second marginal is π\piπ by the stationary grid-law assumption.

Apply the scalar recurrence bound to the derived inequality and compose it with the transport comparison.

The defect has size b=(33/20)Lhhdb=(33/20)Lh\sqrt{hd}b=(33/20)Lhhd​, and this size is uniform in kkk because the supplied moment bounds hold on every segment. The recurrence is consequently homogeneous in its constants. Its initial value remains the norm of the supplied pair, so this bound retains the cost of the supplied initial coupling until the subsequent infimum argument.
