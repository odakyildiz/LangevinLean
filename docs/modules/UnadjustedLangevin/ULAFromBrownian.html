An intermediate bound with a supplied stationary Brownian reference

This auxiliary endpoint already derives the integral equation, continuity and moment bounds from the Brownian coordinates and potential assumptions. It keeps stationarity of the constructed reference segments as an explicit premise.

Mathematical statement and proof

The Brownian-reference constructor supplies stationary segments, score bound Ld\sqrt{Ld}Ld​, exact noise norm 2dt\sqrt{2d}\sqrt t2d​t​, and endpoint increments matching the actual Euler innovations. The potential comparison theorem derives m≤Lm\le Lm≤L. Apply the small-step analytic reference theorem and simplify the start identity S0(0)=Y0S_0(0)=Y_0S0​(0)=Y0​ to obtain

W2(Law⁡(Xk),π)≤(1−mh)k∥X0−Y0∥2+3320Lmhd.W_2(\operatorname{Law}(X_k),\pi)\le(1-mh)^k\|X_0-Y_0\|_2+\frac{33}{20}\frac Lm\sqrt{hd}.W2​(Law(Xk​),π)≤(1−mh)k∥X0​−Y0​∥2​+2033​mL​hd​.

This statement uses the supplied initial realization, not an infimum over couplings. Its stationarity premise is removed by CanonicalULA, where independent Brownian sources and the Gibbs-stationarity theorem are assembled.
