An intermediate bound with a supplied stationary Brownian reference

This auxiliary endpoint already derives the integral equation, continuity and moment bounds from the Brownian coordinates and potential assumptions. It keeps stationarity of the constructed reference segments as an explicit premise.

Mathematical statement and proof

Build the reference from actual Brownian segments using the displayed all-time Gibbs-law premise. Strong convexity proves finite partition and m≤Lm\le Lm≤L, while Brownian laws prove the noise radius and the Gibbs score theorem proves its drift bound. Apply the analytic L2L^2L2 theorem with the supplied joint initialization, yielding its actual initial class distance. This intermediate theorem retains its explicit stationarity premise.
