Compare entropy using derivatives only at positive times

Gaussian regularization naturally supplies derivatives for positive times. The scalar comparison here uses ordinary derivatives on 0<t<T0<t<T0<t<T and continuity on [0,T][0,T][0,T]; neither endpoint needs a derivative. A second theorem computes actual KL derivatives from local relative-density data only in that open interval. The existing global ULA endpoint retains its earlier interface; these lemmas provide a more flexible route for a future positive-time construction.
