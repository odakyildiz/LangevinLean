Relative entropy along an identified density path

Density entropy is the real conversion of the actual KL divergence of the tilted measure. With finite-entropy guards, LSI and a supplied dissipation inequality give exponential entropy decay along this path.

Mathematical statement and proof

Define the real entropy of a specified relative density as Hν(r)=KL⁡(rν∣ν)RH_\nu(r)=\operatorname{KL}(r\nu\mid\nu)_{\mathbb R}Hν​(r)=KL(rν∣ν)R​. It uses the same tiltedMeasure and actual Mathlib KL as the LSI definition. Applications must separately establish finite KL before using it as an ordinary entropy value.

Mathematical statement and proof

At each interpolation time, positivity, C1C^1C1 regularity, normalization, and finite KL/Fisher allow IsLogSobolev.entropy_le_fisher to give 2αH(t)≤I(t)2\alpha H(t)\le I(t)2αH(t)≤I(t). Combine this with the explicit right-dissipation identity and entropy continuity in entropy_decay_of_dissipation. The conclusion is decay at rate 2α2\alpha2α for that admissible density path; identifying an actual evolution with the path remains an application obligation.
