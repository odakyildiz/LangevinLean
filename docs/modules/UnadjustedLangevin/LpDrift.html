The actual gradient on square-integrable random variables

Let PPP be a finite measure on Ω\OmegaΩ. The first five results need only a normed additive commutative group HHH; all Lipschitz constants LLL are nonnegative. When HHH is a real Banach space, L2(P;H)L^2(P;H)L2(P;H) provides the Banach space needed for the local-defect estimate. For a Lipschitz vector field g:H→Hg:H\to Hg:H→H, construct the operator G[X]=[g∘X]\mathcal G[X]=[g\circ X]G[X]=[g∘X], including the case g(0)≠0g(0)\ne0g(0)=0. Finiteness of PPP ensures the constant offset is square integrable.

The gradient results use a real Hilbert space HHH. The two score-moment lemmas need only a real inner-product space, without completeness. Whenever g=∇Ug=\nabla Ug=∇U, this is the potential’s actual gradient, and the resulting L2L^2L2 recursion is proved to represent the original pointwise ULA chain.

01Center a Lipschitz vector field §

Mathematical statement and proof

In a normed additive group HHH, if g:H→Hg:H\to Hg:H→H is LLL-Lipschitz, then so is

g~(x):=g(x)−g(0).\widetilde g(x):=g(x)-g(0).g​(x):=g(x)−g(0).

For arbitrary x,yx,yx,y, the common offset cancels:

∥g~(x)−g~(y)∥=∥g(x)−g(y)∥≤L∥x−y∥.\|\widetilde g(x)-\widetilde g(y)\|=\|g(x)-g(y)\|\le L\|x-y\|.∥g​(x)−g​(y)∥=∥g(x)−g(y)∥≤L∥x−y∥.

This is precisely the required Lipschitz inequality.
