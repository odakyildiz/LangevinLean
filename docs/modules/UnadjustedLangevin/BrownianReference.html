The endpoint at local time hhh is used as the initial class of the next segment. Thus consecutive segments agree at the endpoints as L2L^2L2 classes.

Normalize the endpoint input to define the Euler innovation. Multiplication by 2h\sqrt{2h}2h​ recovers the same reference increment. Continuity, the integral equation, joining, and the noise moments follow from the construction. If every segment time has Gibbs law, the Gibbs gradient moment gives the remaining reference drift bound. That stationary-law property is still a hypothesis here and is proved separately.

02The defining properties of the segment §

Mathematical statement and proof

The selected solution has continuity, the time-zero initial value, the gradient integral equation on [0,h][0,h][0,h], and the exact noise norm. These four properties describe the selected segment independently of which solution is selected.

The four properties have distinct later uses. Continuity makes the drift time integral meaningful. The initial-value identity permits adjoining intervals. The integral equation gives the local Euler drift defect after subtraction. Finally the exact Brownian norm controls reference increments quantitatively. These four properties are used in the subsequent coupling estimate.

03The successive reference knots §

Mathematical statement and proof

Set the zeroth knot to the prescribed initial variable. Define the next knot to be the endpoint at local time hhh of the segment started at the current knot. This recursion ensures consecutive segments meet exactly as L2L^2L2 classes.

Write K0=YinK_0=Y^{\mathrm{in}}K0​=Yin and Kn+1=Yh(n)K_{n+1}=Y^{(n)}_hKn+1​=Yh(n)​, where the nnn-th local solution starts at KnK_nKn​. This is an ordinary recursion in the space of square-integrable states. Each endpoint belongs to that space by the solution construction. It fixes all future segment initial values from the same original state and Brownian source.

04The reference segments §

Mathematical statement and proof

At index nnn, select a restarted Brownian-driven segment with the recursively constructed nnn-th knot as initial state. The absolute noise start is nhnhnh, so all segments are driven by increments of the same Brownian process.

The segment index changes both its initial state and its absolute noise interval. Its equation uses increments beginning at nhnhnh, rather than restarting an unrelated Brownian process at each iteration. Consequently the endpoint increment used for the Euler innovation is the same increment appearing in this reference segment. The two equal endpoint increments therefore cancel in the synchronous comparison.

05The starting value of each segment §

Mathematical statement and proof

The chosen-segment specification states its value at zero equals its supplied initial state. Here that state is the nnn-th knot, so Y0(n)=KnY^{(n)}_0=K_nY0(n)​=Kn​ follows directly by specialization.

At local time zero the drift integral and Brownian increment both vanish. The segment equation thus gives Y0(n)=KnY^{(n)}_0=K_nY0(n)​=Kn​. Together with Kn=Yh(n−1)K_n=Y^{(n-1)}_hKn​=Yh(n−1)​ for n>0n>0n>0, this proves exact joining. The error from joining segments is therefore zero at every boundary.

06The initial reference knot §

Mathematical statement and proof

Apply the segment-start identity at n=0n=0n=0, then unfold the zeroth knot. The constructed reference therefore begins at exactly the prescribed random variable, preserving its chosen joint realization with the numerical initialization.

The first knot is the prescribed random vector, not merely a new variable with the same law. Hence the first reference segment retains the exact initial coupling with the numerical chain. For each arbitrary initial coupling, their root mean-square separation must remain the initial error used by the synchronous argument.

07The endpoint Euler innovations §

Mathematical statement and proof

Normalize the segment endpoint noise by 1/2h1/\sqrt{2h}1/2h​. This defines the L2L^2L2 innovation used by the Euler chain, so it shares the exact Brownian increment driving the reference segment.

The endpoint input is Nnh(h)=2(B(n+1)h−Bnh)N_{nh}(h)=\sqrt2(B_{(n+1)h}-B_{nh})Nnh​(h)=2​(B(n+1)h​−Bnh​). Dividing it by 2h\sqrt{2h}2h​ gives (B(n+1)h−Bnh)/h(B_{(n+1)h}-B_{nh})/\sqrt h(B(n+1)h​−Bnh​)/h​, the standard Brownian increment normalization. Defining the innovation from the same input ensures that multiplication by the Euler amplitude recovers the reference noise exactly; its Gaussian law is verified separately.

08Identification of endpoint noise §

Mathematical statement and proof

For h>0h>0h>0, 2h≠0\sqrt{2h}\ne02h​=0. Multiply the normalized noise class by 2h\sqrt{2h}2h​ and cancel the inverse scalar. The resulting equality identifies the Euler noise contribution with the same Brownian endpoint input in the integral equation.

Positivity of hhh makes 2h\sqrt{2h}2h​ strictly positive, so scalar division and multiplication cancel. Thus 2h ξn=Nnh(h)\sqrt{2h}\,\xi_n=N_{nh}(h)2h​ξn​=Nnh​(h) as square-integrable random vectors. This equality is stronger than agreement in distribution: it allows the two noise terms to disappear when subtracting the Euler update and the reference endpoint equation on their common space.

09The stationary Brownian reference §

Mathematical statement and proof

Use the constructed segments as the reference family. Their specification proves continuity and the integral equation; recursive knots prove endpoint compatibility; normalized noise proves endpoint matching; Gibbs-score moment transfer proves the drift bound. The supplied all-time Gibbs-law premise remains visible and is later proved by the stationarity construction.

Assuming every reference time has Gibbs law, the score moment gives ∥∇U(Yt(n))∥2≤Ld\|\nabla U(Y_t^{(n)})\|_2\le\sqrt{Ld}∥∇U(Yt(n)​)∥2​≤Ld​. The Brownian construction supplies ∥Nnh(t)∥2=2dt\|N_{nh}(t)\|_2=\sqrt{2d}\sqrt t∥Nnh​(t)∥2​=2d​t​. Along with segment joining and endpoint noise matching, these bounds meet the analytic coupling hypotheses. Stationarity remains an explicit input at this intermediate stage, rather than a consequence of the integral equation alone.

10The reference under strong convexity §

Mathematical statement and proof

Positive strong convexity gives a finite positive Gibbs partition and finite target moments. Apply the reference construction using these target properties and the Brownian endpoint-noise identities. Its all-time stationary-law premise remains explicit at this stage and is supplied later by the invariant-approximation argument.

Positive strong convexity implies a finite positive Gibbs partition and a finite second moment. These normalization and integrability facts verify the target normalization and integrability requirements before the reference is assembled. The remaining law premise says that the constructed solution has this target distribution at every segment time. A later stationarity proof supplies that premise using invariant approximations and a continuous-limit argument.
