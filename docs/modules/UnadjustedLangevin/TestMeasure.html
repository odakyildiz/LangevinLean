Compactly supported smooth tests determine a finite measure

On a finite-dimensional real normed space, finite measures agreeing on all compactly supported smooth tests are equal. Agreement on compactly supported C2C^2C2 tests is sufficient as well.

01Compare Radon–Nikodym densities §

Mathematical statement and proof

Let ξ=μ+ν\xi=\mu+\nuξ=μ+ν, so both measures are absolutely continuous with respect to ξ\xiξ. Their finite Radon–Nikodym densities are locally integrable. Rewrite the given test integrals against these densities; their difference integrates to zero against every compactly supported smooth test. The fundamental lemma for test functions gives equality of the real-valued densities ξ\xiξ-almost everywhere. Finiteness allows conversion back to extended densities, and the Radon–Nikodym reconstruction formulas give μ=ν\mu=\nuμ=ν. The C2C^2C2 version applies this result because every smooth test is C2C^2C2.
