Coordinate Gaussian moments and L² Brownian continuity

Coordinatewise Gaussian laws suffice for the second moment E∥X∥2=dv\mathbb E\|X\|^2=dvE∥X∥2=dv. This module carefully obtains Brownian L2L^2L2 continuity and increment norms without assuming independence between spatial coordinates.

01Sum coordinate second moments §

Mathematical statement and proof

If each coordinate Xi∼N(0,v)X_i\sim\mathcal N(0,v)Xi​∼N(0,v), it belongs to L2L^2L2 and has second moment vvv. Finite-dimensional L2L^2L2 membership is coordinatewise, and ∥X∥2=∑iXi2\|X\|^2=\sum_iX_i^2∥X∥2=∑i​Xi2​, so integration gives E∥X∥2=dv\mathbb E\|X\|^2=dvE∥X∥2=dv. For an existing L2L^2L2 class this is ∥X∥22=dv\|X\|_2^2=dv∥X∥22​=dv, hence ∥X∥2=dv\|X\|_2=\sqrt{dv}∥X∥2​=dv​. Passing a measurable variable to its L2L^2L2 class changes no coordinate law. Scalar multiplication yields ∥2X∥2=2dv\|\sqrt2X\|_2=\sqrt{2d}\sqrt v∥2​X∥2​=2d​v​.

03Build a continuous L²-valued path §

Mathematical statement and proof

Define Wt\mathsf W_tWt​ to be the L2L^2L2 class of WtW_tWt​. Its representative agrees with WtW_tWt​ almost everywhere; differences therefore have coordinate laws N(0,∣t−s∣)\mathcal N(0,|t-s|)N(0,∣t−s∣). Consequently

∥Wt−Ws∥2=d∣t−s∣.\|\mathsf W_t-\mathsf W_s\|_2=\sqrt{d|t-s|}.∥Wt​−Ws​∥2​=d∣t−s∣​.

The right side tends to zero as t→st\to st→s, proving continuity. Its zero-time norm is zero. Setting the two times to a+t,aa+t,aa+t,a gives the exact scaled increment norm.

04Extend the time argument to the real line §

Mathematical statement and proof

For interval-integral APIs define WtR=Wmax⁡(t,0)\mathsf W_t^{\mathbb R}=\mathsf W_{\max(t,0)}WtR​=Wmax(t,0)​. The nonnegative-part map is continuous, so this extension is continuous and vanishes at zero.
