The public ULA import surface

This umbrella module imports the deterministic contraction argument, its probability and Brownian foundations, the unconditional Gaussian ULA endpoints and the conditional LSI development. It contains no additional theorem or proof.

This umbrella file has no local proof body. Its import declarations assemble the proved deterministic, probabilistic and entropy modules into one library entry point. To inspect an individual mathematical argument, follow the corresponding module page; to verify the assembled library, run lake build from the repository root.

01The strongly convex Wasserstein route §

Mathematical statement and proof

The imported modules prove Gibbs normalization and score moments, construct independent Brownian coordinates and L2L^2L2 Langevin solutions, establish Gibbs stationarity by invariant Metropolis approximation, and assemble a stationary coupling reference for every finite initial coupling. Infimizing the resulting cost gives
