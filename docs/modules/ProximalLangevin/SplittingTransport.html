Mathematical statement and proof

If q=0q=0q=0, one finite coupling already gives the result. If the target square is at most ccc, the conclusion is immediate. Otherwise set r=(W2(μ′,ν′)2−c)/qr=\sqrt{(W_2(\mu',\nu')^2-c)/q}r=(W2​(μ′,ν′)2−c)/q​. Each coupling estimate implies r≤cost⁡(p)r\le\operatorname{cost}(p)r≤cost(p); infinite-cost couplings also satisfy this extended inequality. Hence r≤inf⁡pcost⁡(p)=W2(μ,ν)r\le\inf_p\operatorname{cost}(p)=W_2(\mu,\nu)r≤infp​cost(p)=W2​(μ,ν). Square this nonnegative inequality and multiply by qqq to obtain

W2(μ′,ν′)2≤qW2(μ,ν)2+c.W_2(\mu',\nu')^2\le qW_2(\mu,\nu)^2+c.W2​(μ′,ν′)2≤qW2​(μ,ν)2+c.

Finiteness justifies every extended-to-real conversion.

Write A=W2(μ′,ν′)2A=W_2(\mu',\nu')^2A=W2​(μ′,ν′)2, and suppose every finite-cost input coupling satisfies A≤qC2+cA\le qC^2+cA≤qC2+c. If q=0q=0q=0, one finite-cost coupling already proves A≤cA\le cA≤c. If A≤cA\le cA≤c, the result is immediate from q≥0q\ge0q≥0. Otherwise set r=(A−c)/qr=\sqrt{(A-c)/q}r=(A−c)/q​; then every finite coupling has cost at least rrr, and infinite-cost couplings also satisfy this lower bound in the extended order.

The operation le_iInf now proves r≤W2(μ,ν)r\le W_2(\mu,\nu)r≤W2​(μ,ν) directly from the definition as an infimum. The finite-distance hypothesis justifies passing to real values. Squaring and multiplying by qqq gives A≤qW2(μ,ν)2+cA\le qW_2(\mu,\nu)^2+cA≤qW2​(μ,ν)2+c. This is why the proof does not need existence of an optimal transport plan.
