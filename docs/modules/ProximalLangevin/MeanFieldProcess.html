A mean-field process can be constructed as an ordinary integral equation in the complete space of square-integrable random joint states. A bounded linear averaging operator replaces only the parameter score by its expectation. Lipschitzness of the actual gradient permits Picard construction, and projection then derives a deterministic parameter path coupled to the actual latent law.

Work on a probability space QQQ, with H=L2(Q;Rdθ+dx)H=L^2(Q;\mathbb R^{d_\theta+d_x})H=L2(Q;Rdθ​+dx​). A potential VVV with globally LLL-Lipschitz gradient defines the actual mean-field drift. Its continuous finite-horizon integral solution is constructed by the Banach-space Picard theorem.

01Expectation is a bounded linear map from L² §

Mathematical statement and proof

The norm-of-integral inequality and ∥X∥L1≤∥X∥L2\|X\|_{L^1}\le\|X\|_{L^2}∥X∥L1​≤∥X∥L2​ on a probability space give ∥EQX∥≤∥X∥2\|\mathbb E_Q X\|\le\|X\|_2∥EQ​X∥≤∥X∥2​. Bochner additivity and scalar linearity therefore define a bounded linear map E:H→E\mathcal E:H\to EE:H→E with operator norm at most one. The evaluation lemma records that its value is the actual integral.

Formal correspondence: norm_lp_expectation_le : On a probability space, the actual expectation is bounded by the L² norm. lpExpectationCLM : Actual Bochner expectation as a bounded linear map out of L².

Bochner integration is linear on square-integrable random variables, since probability normalization implies integrability. The norm bound follows from the norm-of-integral inequality followed by Cauchy–Schwarz. Thus expectation is continuous with norm at most one. As a bounded linear map, it commutes with later continuous time integrals, which is needed when extracting the deterministic parameter equation.

02Coordinate projections and a parameter inclusion §

Mathematical statement and proof

Define Px(θ,x)=xP_x(\theta,x)=xPx​(θ,x)=x and Iθ(θ)=(θ,0)I_\theta(\theta)=(\theta,0)Iθ​(θ)=(θ,0). Their coordinate identities follow by evaluating the definitions. The parameter inclusion inserts zeros in all latent coordinates. The latent projection forgets the parameter coordinates. Expanding the Euclidean square shows that the inclusion preserves norms and the projection does not increase them. These coordinate maps act pointwise on square-integrable variables and retain their bounded linearity, giving precise control of the projected integral equations.

03A true latent mask erases all parameter coordinates §

Mathematical statement and proof

Set Mx=I−IθPθM_x=I-I_\theta P_\thetaMx​=I−Iθ​Pθ​. Its parameter block is zero and its latent block is unchanged. Expanding the Euclidean squared norm shows ∥Mxz∥2≤∥z∥2\|M_xz\|^2\le\|z\|^2∥Mx​z∥2≤∥z∥2, since the discarded parameter square is nonnegative. Thus the mask is nonexpansive and remains bounded after composition on L2L^2L2.

Formal correspondence: jointLatentMaskCLM : The actual latent-coordinate projection on the joint space.

The mask MxM_xMx​ removes the orthogonal parameter part and keeps the latent part. Its squared norm is exactly the sum of latent coordinate squares, bounded by the full sum. Therefore masking preserves square integrability and continuity of an L2L^2L2-valued input. In particular it produces a latent-only Brownian input whose parameter projection is identically zero.

04Average exactly the parameter block §

Mathematical statement and proof

Construct the bounded linear map

MX=const⁡(IθPθEQX)+MxX.\mathcal M X=\operatorname{const}(I_\theta P_\theta\mathbb E_QX)+M_xX.MX=const(Iθ​Pθ​EQ​X)+Mx​X.

The expectation estimate and coordinate contractions bound each term by ∥X∥2\|X\|_2∥X∥2​, so ∥MX∥2≤2∥X∥2\|\mathcal M X\|_2\le2\|X\|_2∥MX∥2​≤2∥X∥2​. Linearity then proves Lip⁡(M)≤2\operatorname{Lip}(\mathcal M)\le2Lip(M)≤2. This is a conservative sufficient constant.

Formal correspondence: meanFieldAverageCLM : Average the parameter coordinates and retain the latent coordinates as actual random variables. This is a bounded linear map, not an assumed drift.

The averaging operator maps (Θ,X)(\Theta,X)(Θ,X) to (EΘ,X)(\mathbb E\Theta,X)(EΘ,X), with the expected parameter viewed as a constant random variable. Its two terms are bounded linear, so the sum has the stated sufficient norm bound two. This operator averages the parameter score only; it does not replace each latent force by its expectation. That distinction produces the intended interacting parameter–latent mean-field dynamics.

05Define the actual drift and apply Picard §

Mathematical statement and proof

Set AV(X)=M(∇V(X))\mathcal A_V(X)=\mathcal M(\nabla V(X))AV​(X)=M(∇V(X)). The Nemytskii map for the actual Lipschitz gradient preserves L2L^2L2 and has constant LLL, so Lip⁡(AV)≤2L\operatorname{Lip}(\mathcal A_V)\le2LLip(AV​)≤2L. For any continuous HHH-valued input BBB with B0=0B_0=0B0​=0, and any T≥0T\ge0T≥0, Picard constructs continuous YYY with Y0=YinY_0=Y^{\rm in}Y0​=Yin and

Yt−Yin=−∫0tAV(Ys)ds+Bt,0≤t≤T.Y_t-Y^{\rm in}=-\int_0^t\mathcal A_V(Y_s)ds+B_t,\qquad0\le t\le T.Yt​−Yin=−∫0t​AV​(Ys​)ds+Bt​,0≤t≤T.

The proof is an existence theorem in the actual complete Banach space HHH.

The averaging operator retains the latent gradient pointwise and replaces the parameter gradient by its expectation as a constant random variable. Expectation is a bounded linear map L2→HL^2\to HL2→H of norm at most one on a probability space, and the coordinate masks are orthogonal contractions. Thus the averaged drift is globally Lipschitz once the true joint score is Lipschitz. Picard's theorem applies in the complete Hilbert space of square-integrable joint states to a continuous additive input, constructing the actual integral solution on every finite horizon.

Formal correspondence: lpMeanFieldDrift : The actual mean-field drift: expected parameter force and pointwise latent force. lpMeanFieldDrift_lipschitz : A conservative global Lipschitz constant for the constructed drift. exists_lp_meanField_integral : Picard constructs the continuous mean-field L² integral solution from its actual gradient and a continuous L² additive input on every finite horizon.

A Lipschitz score defines a Lipschitz composition map on L2L^2L2 and has affine growth, so it is everywhere defined on the state Hilbert space. Composing with the averaging operator gives constant at most 2L2L2L. For a continuous additive input, subtracting that input reduces the problem to a standard nonautonomous Lipschitz integral equation. Picard yields a continuous finite-horizon solution and the stated integral identity.
