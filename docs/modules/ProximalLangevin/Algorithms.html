01The pairwise map in coordinates §

Mathematical statement and proof

Definition. Let PPP be any map from the pair space Rdθ×Rdx\mathbb R^{d_\theta}\times\mathbb R^{d_x}Rdθ​×Rdx​ to itself, and write P(w)=([P(w)]θ,[P(w)]x)P(w)=([P(w)]_\theta,[P(w)]_x)P(w)=([P(w)]θ​,[P(w)]x​). The pairwise map P\mathcal PP on the state space is defined by

All NNN pairs are formed with the same current parameter θ\thetaθ. 02The PIPULA, MYIPLA and PIPGLA update maps §

Definitions. Let PPP be a map of the pair space, g1g_1g1​ a real function on the pair space, γ,η∈R\gamma,\eta\in\mathbb Rγ,η∈R, and z,ξz,\xiz,ξ states.
