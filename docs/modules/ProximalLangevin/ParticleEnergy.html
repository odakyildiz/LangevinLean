01Averaging squares in the shared parameter §

Mathematical statement and proof

Cauchy–Schwarz for finite sums gives N(N−1∑ibi)2≤∑ibi2N(N^{-1}\sum_i b_i)^2\le\sum_i b_i^2N(N−1∑i​bi​)2≤∑i​bi2​. Apply it separately to each parameter coordinate of the pairwise outputs. Each latent block instead satisfies an exact equality after multiplying by NNN, since (N)2=N(\sqrt N)^2=N(N​)2=N. Summing all coordinates yields

∥Pair⁡P(z)−a∥2≤1N∑i∥P(Jiz)−Jia∥2.\|\operatorname{Pair}_P(z)-a\|^2\le\frac1N\sum_i\|P(J_i z)-J_i a\|^2.∥PairP​(z)−a∥2≤N1​i∑​∥P(Ji​z)−Ji​a∥2.

02Sum genuine proximal energy inequalities §

Mathematical statement and proof

The roadmap on v3 page 19 identifies averaged pairwise proximity with the proximal map of the lifted averaged potential. Shared parameter coordinates prevent that identity in general. The needed energy conclusion can nevertheless be proved without changing the algorithm.

For arbitrary pair outputs, Jensen's inequality for their averaged parameter gives

∥Pair⁡P(z)−a∥2≤1N∑i=1N∥P(Jiz)−Jia∥2. \|\operatorname{Pair}_P(z)-a\|^2 \le\frac1N\sum_{i=1}^N\|P(J_i z)-J_i a\|^2. ∥PairP​(z)−a∥2≤N1​i=1∑N​∥P(Ji​z)−Ji​a∥2.

The scaled latent-coordinate contribution is an exact identity; only the parameter contribution requires an inequality. Apply the single-pair proximal energy result to every summand. Using ∑i∥Ji(z−a)∥2=N∥z−a∥2\sum_i\|J_i(z-a)\|^2=N\|z-a\|^2∑i​∥Ji​(z−a)∥2=N∥z−a∥2 and G2=N−1∑ig2∘JiG_2=N^{-1}\sum_i g_2\circ J_iG2​=N−1∑i​g2​∘Ji​ gives

∥Pair⁡Pλ(z)−a∥2≤∥z−a∥2−2λ(G2(z)−G2(a))+λ2C. \|\operatorname{Pair}_{P_\lambda}(z)-a\|^2 \le\|z-a\|^2-2\lambda\bigl(G_2(z)-G_2(a)\bigr)+\lambda^2C. ∥PairPλ​​(z)−a∥2≤∥z−a∥2−2λ(G2​(z)−G2​(a))+λ2C.

This lifted energy inequality is fully proved for actual minimizers. It repairs the deterministic proof bridge needed in Corollary A.13 while preserving the paper's particle algorithm and its original nonsmooth energy. It is still only one part of the full stochastic convergence proof.

The failure of the lifted-proximal identity has a concrete Lipschitz witness. Take N=2N=2N=2, g2(θ,x)=∣θ−x∣g_2(\theta,x)=|\theta-x|g2​(θ,x)=∣θ−x∣, smoothing one, common input parameter 111 and physical particles (0,4)(0,4)(0,4). The genuine pairwise proximal points are (1/2,1/2)(1/2,1/2)(1/2,1/2) and (2,3)(2,3)(2,3). Averaging only their parameter components gives (5/4,1/2,3)(5/4,1/2,3)(5/4,1/2,3). In the lifted proximal objective with its scaled particle norm, the feasible point (1,1,3)(1,1,3)(1,1,3) has value 3/23/23/2, while this pairwise output has value 51/3251/3251/32. The strict inequality is kernel checked below. The averaged energy proof above repairs the necessary estimate without this false identity.
