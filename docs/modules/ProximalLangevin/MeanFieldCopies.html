Independent copies and the empirical parameter-force residual

References and publication status for this development

Published source; unpublished corrected proofs

The algorithms are from the published paper below; the correspondence audit uses arXiv:2406.14292v3 (29 May 2025). The corrected MYIPLA, PIPGLA, and MYPGD bounds and proofs presented here are unpublished. The audit records their differences from the paper’s printed rates and constants, and the claims that remain outside the formalization.

  • Paula Cordero Encinar, Francesca Romana Crucinio, and Omer Deniz Akyildiz (2025). Proximal Interacting Particle Langevin Algorithms. Proceedings of the Forty-first Conference on Uncertainty in Artificial Intelligence, Proceedings of Machine Learning Research 286, 1220–1265. Audited version: arXiv:2406.14292v3

Independent copies of the mean-field state give an empirical drift residual with exact N−1/2N^{-1/2}N−1/2 norm factor. Starting with a joint random state on QQQ, use the finite product P=Q⊗NP=Q^{\otimes N}P=Q⊗N and its coordinate pullbacks. When the reference parameter is deterministic, all copies have the same parameter while their latent components are independent. The copy maps are bounded and linear, so they commute with the reference integral equation. All latent drift residuals cancel; only the centered empirical parameter force remains.

01The measure-preserving coordinate copy map §

Mathematical statement and proof

For product coordinate ωi\omega_iωi​ define CiX=X∘ωiC_iX=X\circ\omega_iCi​X=X∘ωi​. Evaluation preserves the reference measure, so pullback is an L2L^2L2 isometry and a bounded linear map. Its representative equals X(ωi)X(\omega_i)X(ωi​) almost surely. Coordinate substitution gives Ci(CX)=C(CiX)C_i(CX)=C(C_iX)Ci​(CX)=C(Ci​X) for bounded linear CCC, and constants satisfy Ci(const⁡x)=const⁡xC_i(\operatorname{const}x)=\operatorname{const}xCi​(constx)=constx.

The evaluation ω↦ωi\omega\mapsto\omega_iω↦ωi​ has pushforward QQQ; hence integration of ∥X(ωi)∥2\|X(\omega_i)\|^2∥X(ωi​)∥2 gives the original second moment. Pullback is consequently an isometry on L2L^2L2. These pointwise and integral identities justify copying the projected reference equations.

02The centered empirical fluctuation norm §

Mathematical statement and proof

For N>0N>0N>0 define CX=X−const⁡(EX)\mathcal C X=X-\operatorname{const}(\mathbb EX)CX=X−const(EX) and ΔN(X)=N−1∑iCiX−const⁡(EX)\Delta_N(X)=N^{-1}\sum_iC_iX-\operatorname{const}(\mathbb EX)ΔN​(X)=N−1∑i​Ci​X−const(EX). Finite-sum representative identities identify the latter with the centered sample mean. Independence on the product space gives

∥ΔN(X)∥L2(P)2=1N∥CX∥L2(Q)2,∥ΔN(X)∥2=∥CX∥2N.\|\Delta_N(X)\|_{L^2(P)}^2=\frac1N\|\mathcal C X\|_{L^2(Q)}^2,\qquad\|\Delta_N(X)\|_2=\frac{\|\mathcal C X\|_2}{\sqrt N}.∥ΔN​(X)∥L2(P)2​=N1​∥CX∥L2(Q)2​,∥ΔN​(X)∥2​=N​∥CX∥2​​.

The pullback X↦X(ωi)X\mapsto X(\omega_i)X↦X(ωi​) preserves QQQ and is a linear isometry. Thus the centered copy sum is an L2L^2L2 vector represented by that sample mean. The exact variance statement is

∥empirical fluctuation∥22=∥X−EX∥22N,\|\text{empirical fluctuation}\|_2^2=\frac{\|X-\mathbb EX\|_2^2}{N},∥empirical fluctuation∥22​=N∥X−EX∥22​​,

Taking nonnegative square roots gives factor N−1/2N^{-1/2}N−1/2. The centered force norm is divided by N\sqrt NN​. This uses independence of reference copies; the later interacting particle states are not assumed independent.

03The reference particle state with deterministic parameter §

Mathematical statement and proof

Define the reference particle state by

RN(X)=(const⁡(EPθX), (PxCiX)i).\mathcal R_N(X)=\left(\operatorname{const}(\mathbb E P_\theta X),\ (P_xC_iX)_i\right).RN​(X)=(const(EPθ​X), (Px​Ci​X)i​).

Bounded linear maps commute with expectation, and a constant has its original value as expectation under a probability measure. Thus if PθX=const⁡θP_\theta X=\operatorname{const}\thetaPθ​X=constθ, the parameter component of RN(X)\mathcal R_N(X)RN​(X) is const⁡θ\operatorname{const}\thetaconstθ.

The latent coordinates are independent coordinate copies, while the deterministic parameter is unchanged. The construction is a bounded linear map, which permits passage through the reference time integral.

Formal correspondence: lpExpectationCLM_compLp : Actual expectation commutes with any bounded linear map. iidMeanFieldCopiesCLM : Mean-field parameter expectation and genuine iid latent copies.

04Reconstruction and drift composition for copied pairs §

Mathematical statement and proof

Recombining the parameter and latent projections recovers the original L2L^2L2 vector. For deterministic parameter this gives JiRN(X)=CiXJ_i\mathcal R_N(X)=C_iXJi​RN​(X)=Ci​X. Composition of the copied state with a Lipschitz pointwise drift is the same as copying the composition, since both representatives equal b(X(ωi))b(X(\omega_i))b(X(ωi​)) almost surely.

For the gradient, this common representative is ∇V(X(ωi))\nabla V(X(\omega_i))∇V(X(ωi​)). Hence each reconstructed reference pair has precisely the copied joint drift. This equality causes the latent components to cancel in the particle-minus-reference drift.

Formal correspondence: lpJointPair_projections : Reconstructing one pair from a joint random variable loses no coordinates. iidMeanFieldCopies_joint : Each reference pair is the selected genuine joint copy when its parameter is deterministic. This is an equality of actual L² random variables. iidCopyCLM_lpDrift : Actual pointwise Lipschitz drift commutes with an iid pullback.

Earlier results used here: ULA-SC, Section 3.13.2; ULA-SC, Section 3.13.3; IPLA-SC, Section 3.1.1.

05The empirical parameter-force drift residual §

Mathematical statement and proof

Apply the particle drift to RN(X)\mathcal R_N(X)RN​(X) and compare it with RN(AV(X))\mathcal R_N(\mathcal A_V(X))RN​(AV​(X)). Reconstruction and gradient commutation identify all latent components, leaving

AN(RNX)−RN(AVX)=(ΔN(Pθ∇V(X)),0).\mathcal A_N(\mathcal R_NX)-\mathcal R_N(\mathcal A_VX)=\left(\Delta_N(P_\theta\nabla V(X)),0\right).AN​(RN​X)−RN​(AV​X)=(ΔN​(Pθ​∇V(X)),0).

The maximum product norm and sample-mean variance identity give residual norm ∥C(Pθ∇V(X))∥2/N\|\mathcal C(P_\theta\nabla V(X))\|_2/\sqrt N∥C(Pθ​∇V(X))∥2​/N​. In detail, latent coordinate iii combines with the deterministic parameter to recover joint copy iii. The parameter discrepancy is

1N∑i∇θV(θ,Xi)−E∇θV(θ,X).\frac1N\sum_i\nabla_\theta V(\theta,X_i)-\mathbb E\nabla_\theta V(\theta,X).N1​i∑​∇θ​V(θ,Xi​)−E∇θ​V(θ,X).

It is the empirical parameter force minus its expectation. Its norm is the centered single-copy force norm divided by N\sqrt NN​, equivalently ∥C(Pθ∇V(X))∥2/N\|\mathcal C(P_\theta\nabla V(X))\|_2/\sqrt N∥C(Pθ​∇V(X))∥2​/N​. This exact residual supplies the sampling forcing used in the comparison theorem.

Formal correspondence: iidMeanFieldCopies_drift_residual : The finite-particle drift defect at the constructed iid reference is exactly its centered empirical parameter-gradient error. The latent defect is zero. iidMeanFieldCopies_drift_residual_norm : The actual drift defect has its exact independent-sampling norm.
