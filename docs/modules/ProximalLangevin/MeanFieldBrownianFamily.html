An independent Brownian family for all actual particle coordinates

On Q⊗NQ^{\otimes N}Q⊗N, choose parameter Brownian coordinates from copy zero and latent coordinate (i,j)(i,j)(i,j) from copy iii. Injective selection proves independence of complete selected coordinate paths.

01Select distinct copy/coordinate pairs §

Mathematical statement and proof

Map a parameter index jjj to (0,parameter j)(0,\mathrm{parameter}\ j)(0,parameter j), and a latent index (i,j)(i,j)(i,j) to (i,latent j)(i,\mathrm{latent}\ j)(i,latent j). The parameter/latent tags make the two kinds disjoint, and equality within either kind forces equality of the original indices. This proves injectivity. Define the family by evaluating the corresponding source Brownian coordinate in the selected copy; the displayed coordinate identities unfold the selection.

02Each selected process retains its Brownian law §

Mathematical statement and proof

Pullback along product evaluation is measure preserving, so every selected scalar process is standard pre-Brownian. If all source evaluations are measurable, composition with the selected coordinate map proves every new evaluation measurable as well.

03Flatten independent rows and select an injective subfamily §

Mathematical statement and proof

The finite product makes the complete Brownian rows independent. Inside each row, the supplied full coordinate paths are independent. The product-family independence theorem flattens these into independent variables indexed by (i,j)(i,j)(i,j). Precomposing with the injective selection proves independence of all particle coordinates, including parameter and first-particle latent blocks. The canonical Brownian source supplies both the row laws and full-path independence, yielding an explicit complete family.
