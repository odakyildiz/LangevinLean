For the actual splitting map, parameter averaging preserves nonexpansiveness of each joint proximity map. A shared innovation cancels before proximity, so the strongly convex smooth forward contraction survives the composition. This proves pathwise stability for every supplied innovation sequence and every positive proximal scale.

Let N>0N>0N>0, let g1g_1g1​ be differentiable and mmm-strongly convex with L1L_1L1​-Lipschitz gradient, and let g2g_2g2​ be convex and bounded below. 01Jensen handles two independently averaged outputs §

Mathematical statement and proof

Apply the scalar average-square inequality to the difference of the parameter outputs. Each latent difference has its exact scaled square. Thus

∥Pair⁡P(z)−Pair⁡P(w)∥2≤N−1∑i∥P(Jiz)−P(Jiw)∥2.\|\operatorname{Pair}_P(z)-\operatorname{Pair}_P(w)\|^2\le N^{-1}\sum_i\|P(J_i z)-P(J_i w)\|^2.∥PairP​(z)−PairP​(w)∥2≤N−1i∑​∥P(Ji​z)−P(Ji​w)∥2.

If PPP is nonexpansive, each summand is bounded by ∥Ji(z−w)∥2\|J_i(z-w)\|^2∥Ji​(z−w)∥2. Their sum is N∥z−w∥2N\|z-w\|^2N∥z−w∥2, proving that the actual pairwise map is also nonexpansive.

Put Aiz=(θ,Nzi)A_i z=(\theta,\sqrt N z_i)Ai​z=(θ,N​zi​) and Δi=P(Aiz)−P(Aiw)\Delta_i=P(A_i z)-P(A_i w)Δi​=P(Ai​z)−P(Ai​w). The shared parameter is an average, so Jensen gives N∥Δ‾θ∥2≤∑i∥Δi,θ∥2N\|\overline\Delta_\theta\|^2\le\sum_i\|\Delta_{i,\theta}\|^2N∥Δθ​∥2≤∑i​∥Δi,θ​∥2; each latent coordinate is rescaled by N−1/2N^{-1/2}N−1/2, so its corresponding squared identity is exact. Summing yields ∥Pair⁡P(z)−Pair⁡P(w)∥2≤1N∑i∥Δi∥2.\|\operatorname{Pair}P(z)-\operatorname{Pair}P(w)\|^2\le\frac1N\sum_i\|\Delta_i\|^2.∥PairP(z)−PairP(w)∥2≤N1​i∑​∥Δi​∥2. Nonexpansiveness of PPP and ∑i∥Ai(z−w)∥2=N∥z−w∥2\sum_i\|A_i(z-w)\|^2=N\|z-w\|^2∑i​∥Ai​(z−w)∥2=N∥z−w∥2 prove the claimed state-space bound. The positivity of NNN justifies both division and the unscaling.

Formal correspondence: pairwiseMap_difference_sq_le : Averaging only the shared parameter contracts the squared difference relative to the average of all separate pairwise squared differences. pairwiseMap_nonexpansive : A nonexpansive pair map remains nonexpansive after the actual shared parameter averaging and physical-particle scaling.

The two averaged parameter outputs need not coincide pair by pair. Jensen handles their average difference, while latent squares have exact scaled identities. Applying pairwise nonexpansiveness and the replication identity gives a unit Lipschitz constant for the entire averaged map. No assertion that this map is a shared-state proximal minimizer is used in the argument.

02A shared innovation cancels before proximity §

Mathematical statement and proof

The lifted smooth gradient step has strong convexity NmNmNm, gradient constant NL1NL_1NL1​, and step γ/N\gamma/Nγ/N, so its contraction factor is 1−mγ≥01-m\gamma\ge01−mγ≥0. The same Gaussian or deterministic innovation added to both inputs cancels in their difference. Composition with the actual nonexpansive averaged proximal map gives

∥Tλ(z,ξ)−Tλ(w,ξ)∥≤(1−mγ)∥z−w∥.\|T_\lambda(z,\xi)-T_\lambda(w,\xi)\|\le(1-m\gamma)\|z-w\|.∥Tλ​(z,ξ)−Tλ​(w,ξ)∥≤(1−mγ)∥z−w∥.

Induction on the displayed recursion yields factor (1−mγ)n(1-m\gamma)^n(1−mγ)n. This proves stability; a separate stationary reference and local-consistency estimate are needed for convergence to a Gibbs target.

In one shared-noise comparison, the additive Gaussian vector cancels before applying the pairwise proximal map. The smooth forward step contracts by q=1−mγq=1-m\gammaq=1−mγ; the actual proximal minimizer is nonexpansive, so composing the two leaves the same factor. The step restriction proves q≥0q\ge0q≥0, which is needed to multiply the induction inequality. Starting with e0=∥z−w∥e_0=\|z-w\|e0​=∥z−w∥, the successor case gives ek+1≤qek≤qk+1e0e_{k+1}\le q e_k\le q^{k+1}e_0ek+1​≤qek​≤qk+1e0​. This establishes pathwise stability under arbitrary supplied innovations, without stationarity or independence assumptions.

Formal correspondence: pipglaUpdate_shared_noise_contract : PIPGLA contracts synchronously driven initial states at the smooth forward-step rate. No stochastic or equilibrium hypothesis is needed. pipglaChain_shared_noise_contract : Iterating the actual pathwise inequality controls two PIPGLA runs with the same innovations. It supplies stability, rather than a Gibbs bias bound.

For the same innovation, the pre-proximal state difference is exactly the deterministic smooth forward difference. Its contraction factor is q=1−mγq=1-m\gammaq=1−mγ, which is nonnegative under the stated restriction. Composing with a nonexpansive map gives ek+1≤qeke_{k+1}\le q e_kek+1​≤qek​. Induction yields qne0q^n e_0qne0​, independently of Gaussianity or independence, because only equality of the innovations is needed.
