Relative entropy under parameter projection

References and publication status for this development

Unpublished proof

The IPLA LSI proof presented here is unpublished. It applies the ULA entropy theorem to the joint particle Gibbs measure, proves the joint entropy estimate and its normalization by particle number, and bounds the parameter-marginal entropy by data processing. The papers below provide the ULA and IPLA results used in the argument.

  • Santosh S. Vempala and Andre Wibisono (2019). Rapid Convergence of the Unadjusted Langevin Algorithm: Isoperimetry Suffices. Advances in Neural Information Processing Systems 32, 8094–8106. Full paper with appendices
  • Alex Glyn-Davies, Connor Duffin, Ieva Kazlauskaite, Mark Girolami, and Ö. Deniz Akyildiz (2025). Statistical Finite Elements via Interacting Particle Langevin Dynamics. SIAM/ASA Journal on Uncertainty Quantification 13(3), 1200–1227. Audited version: arXiv:2409.07101v2

Project the current state law and the lifted Gibbs law by the same measurable parameter map. The data-processing inequality bounds the projected relative entropy by the joint relative entropy. A finite joint divergence makes the projected divergence finite and permits both to be read as real numbers. This argument needs neither a formula for the marginal density nor strong convexity or a distinguished maximizing parameter.

01The projected target as a probability measure §

Mathematical statement and proof

Put p=pθp=p_\thetap=pθ​ and define ΠNθ=p#ΠN\Pi_N^\theta=p_\#\Pi_NΠNθ​=p#​ΠN​. The continuous linear projection is measurable. For every probability measure μ\muμ,

(p#μ)(Rdθ)=μ(p−1(Rdθ))=μ(RD)=1(p_\#\mu)(\mathbb R^{d_\theta})=\mu(p^{-1}(\mathbb R^{d_\theta}))=\mu(\mathbb R^D)=1(p#​μ)(Rdθ​)=μ(p−1(Rdθ​))=μ(RD)=1.

Thus it preserves probability, both for the current state law and for the reference whenever ΠN\Pi_NΠN​ is normalized. In the conditional entropy result this normalization is part of the logarithmic Sobolev assumption. The definition ΠNθ=(pθ)#ΠN\Pi_N^\theta=(p_\theta)_\#\Pi_NΠNθ​=(pθ​)#​ΠN​ fixes the parameter reference as a measure even when no marginal-potential representation has been established.

Formal correspondence: parameterTarget : The parameter target is the actual lifted Gibbs law projected to its parameter coordinates. Probability normalization remains an explicit premise. parameterLaw_isProbability : Projecting a probability-valued state law preserves probability mass. parameterTarget_isProbability : The Gibbs parameter target is normalized whenever the actual joint target is normalized. No concentration or convexity hypothesis is introduced.

Earlier results used here: IPLA-SC, Section 3.1.1; IPLA-SC, Section 3.1.6; IPLA-SC, Section 3.3.2.

02Data processing for extended relative entropy §

Mathematical statement and proof

For a measurable projection the data-processing inequality states

KL⁡(p#μ∥p#ν)≤KL⁡(μ∥ν).\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le\operatorname{KL}(\mu\Vert\nu).KL(p#​μ∥p#​ν)≤KL(μ∥ν).

Convexity of ulog⁡uu\log uulogu implies that averaging over the discarded coordinates cannot increase divergence. The measure-theoretic theorem expresses this without requiring an explicit conditional density. Its inequality is meaningful in the extended nonnegative reals. If the joint divergence is finite, the inequality also makes the projected divergence finite; conversion of both finite quantities to real numbers then preserves order. This is the finite form used in the numerical bounds.

The parameter projection is a continuous linear map and hence measurable. Data processing gives the extended inequality KL⁡(p#μ∥p#ν)≤KL⁡(μ∥ν)\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le\operatorname{KL}(\mu\Vert\nu)KL(p#​μ∥p#​ν)≤KL(μ∥ν) before any real conversion. A finite joint KL therefore proves finite marginal KL, and only then can ENNReal.toReal_le_toReal transfer the order. This is a divergence statement about the actual pushed-forward target, with no density formula or optimizer concentration assumed.

Formal correspondence: parameter_kl_le_joint : Extended-valued data processing for the common parameter projection. parameter_kl_ne_top_of_joint : Finite joint KL implies finite parameter KL. parameter_klReal_le_joint : The real data-processing inequality, with finiteness of both divergences established before taking their toReal values.

Earlier results used here: IPLA-SC, Section 3.1.1; IPLA-SC, Section 3.1.6.

03Full and per-particle entropy upper bounds §

Mathematical statement and proof

If the full finite joint divergence satisfies H≤BH\le BH≤B, data processing bounds the parameter divergence by BBB. If only H/N≤BH/N\le BH/N≤B is given with N>0N>0N>0, multiplication gives H≤NBH\le NBH≤NB, hence

KL⁡(p#μ∥p#ν)≤NB.\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le NB.KL(p#​μ∥p#​ν)≤NB.

In particular the estimate H/N≤BH/N\le BH/N≤B, multiplied by positive NNN, becomes H≤NBH\le NBH≤NB. Projection then gives upper bound NBNBNB rather than BBB. With iteration notation Hk/N≤BkH_k/N\le B_kHk​/N≤Bk​, the same operation gives Hk≤NBkH_k\le NB_kHk​≤NBk​ and therefore Hkθ≤NBkH_k^\theta\le NB_kHkθ​≤NBk​ rather than BkB_kBk​.

The initial quantity in the resulting parameter estimate is still the full initial joint entropy. Data processing makes the projected initial entropy smaller; it does not justify substituting that smaller number into an upper bound derived for the joint evolution. Both the normalization factor and the initial term must therefore be retained.

Formal correspondence: parameter_kl_bound_of_joint_bound : Any finite real bound on full joint KL is also a parameter-marginal bound. parameter_kl_bound_of_per_particle_bound : A per-particle joint entropy bound controls unscaled parameter KL after multiplication by the particle count.

Earlier results used here: IPLA-SC, Section 3.1.1; IPLA-SC, Section 3.1.6.

04The inequality for the Gibbs parameter projection §

Mathematical statement and proof

Set ν=ΠN\nu=\Pi_Nν=ΠN​ in the generic projection theorem. The definition of ΠNθ\Pi_N^\thetaΠNθ​ gives KL⁡(p#μ∥ΠNθ)≤KL⁡(μ∥ΠN)\operatorname{KL}(p_\#\mu\Vert\Pi_N^\theta)\le\operatorname{KL}(\mu\Vert\Pi_N)KL(p#​μ∥ΠNθ​)≤KL(μ∥ΠN​). Joint finiteness implies projected finiteness, and any finite real joint upper bound therefore transfers to the parameter divergence.

Both laws are projected by the same map. Their normalization and the finite-joint condition are inherited from the joint theorem. This specialization requires no density regularity, particle independence, concentration estimate, or optimizer assumption beyond those used to establish that theorem.

Formal correspondence: parameter_kl_le_gibbs_joint : Extended KL data processing with the actual Gibbs parameter target. parameter_kl_ne_top_of_gibbs_joint : Finite actual Gibbs-relative joint KL gives finite parameter KL. parameter_kl_bound_of_gibbs_joint_bound : A joint KL estimate transfers to the actual Gibbs parameter marginal, without constructing a formula for its marginal density.

Earlier results used here: IPLA-SC, Section 3.1.1; IPLA-SC, Section 3.1.6; IPLA-SC, Section 3.3.2.
