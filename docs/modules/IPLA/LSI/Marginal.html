Module proof · Mathematics alongside Lean

Parameter KL by data processing and guarded real conversion

The parameter reference law is exactly the projection of the actual lifted Gibbs target. Measurable projection decreases extended KL, and finite joint KL makes the real bound transfer valid. This measure-theoretic argument needs no marginal-density or strong-convexity formula.

01Define the projected target and prove its probability property §

Mathematical statement and proof

With p=pθp=p_\thetap=pθ​, define ΠNθ=p#ΠN\Pi_N^\theta=p_\#\Pi_NΠNθ​=p#​ΠN​. The projection is a continuous linear map, hence measurable. For any probability measure μ\muμ, (p#μ)(Rdθ)=μ(p−1(Rdθ))=μ(RD)=1(p_\#\mu)(\mathbb R^{d_\theta})=\mu(p^{-1}(\mathbb R^{d_\theta}))=\mu(\mathbb R^D)=1(p#​μ)(Rdθ​)=μ(p−1(Rdθ​))=μ(RD)=1. This proves probability preservation for any state law and then for the named target whenever ΠN\Pi_NΠN​ is a probability. In the conditional LSI application that normalization comes from the LSI assumption itself.

Correspondence with the displayed declarations.

  • parameterTarget: The parameter target is the actual lifted Gibbs law projected to its parameter coordinates. Probability normalization remains an explicit premise.
  • parameterLaw_isProbability: Projecting a probability-valued state law preserves probability mass.
  • parameterTarget_isProbability: The Gibbs parameter target is normalized whenever the actual joint target is normalized. No concentration or convexity hypothesis is introduced.

02Extended KL decreases under the parameter projection §

Mathematical statement and proof

The shared data-processing theorem for a measurable map yields

KL⁡(p#μ∥p#ν)≤KL⁡(μ∥ν).\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le\operatorname{KL}(\mu\Vert\nu).KL(p#​μ∥p#​ν)≤KL(μ∥ν).

At the density level this is convexity of ulog⁡uu\log uulogu under averaging over forgotten coordinates; the measure theorem does not require a constructed conditional density. If the right-hand divergence is finite, the inequality immediately excludes infinity on the left. Since both extended quantities are finite, order is preserved when taking their real values. This proves the real data-processing inequality with its necessary finiteness guard.

The parameter projection is a continuous linear map and hence measurable. Data processing gives the extended inequality KL⁡(p#μ∥p#ν)≤KL⁡(μ∥ν)\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le\operatorname{KL}(\mu\Vert\nu)KL(p#​μ∥p#​ν)≤KL(μ∥ν) before any real conversion. A finite joint KL therefore proves finite marginal KL, and only then can ENNReal.toReal_le_toReal transfer the order. This is a divergence statement about the actual pushed-forward target, with no density formula or optimizer concentration assumed.

Correspondence with the displayed declarations.

  • parameter_kl_le_joint: Extended-valued data processing for the common parameter projection.
  • parameter_kl_ne_top_of_joint: Finite joint KL implies finite parameter KL.
  • parameter_klReal_le_joint: The real data-processing inequality, with finiteness of both divergences established before taking their toReal values.

03Transfer a full-joint or per-particle bound with the correct factor §

Mathematical statement and proof

If finite full joint KL has real bound H≤BH\le BH≤B, transitivity with real data processing gives parameter KL at most BBB. If instead H/N≤BH/N\le BH/N≤B and N>0N>0N>0, multiplication by the positive count yields H≤NBH\le NBH≤NB, hence

KL⁡(p#μ∥p#ν)≤NB.\operatorname{KL}(p_\#\mu\Vert p_\#\nu)\le NB.KL(p#​μ∥p#​ν)≤NB.

The proof uses the positive-denominator order equivalence before applying the full-joint transfer lemma. This factor is necessary because normalized joint entropy is not the same quantity as parameter-marginal entropy.

If the available estimate is intensive, H/N≤BH/N\le BH/N≤B, positive NNN gives the full joint bound H≤NBH\le NBH≤NB, and data processing then gives marginal KL at most NBNBNB. It does not give marginal KL at most BBB. The initial entropy in the final bound is still full joint entropy: projection decreases initial entropy, so replacing that term by initial parameter entropy would make the right-hand side smaller without a supporting argument.

Correspondence with the displayed declarations.

  • parameter_kl_bound_of_joint_bound: Any finite real bound on full joint KL is also a parameter-marginal bound.
  • parameter_kl_bound_of_per_particle_bound: A per-particle joint entropy bound controls unscaled parameter KL after multiplication by the particle count.

04Specialize all transfers to the actual Gibbs parameter target §

Mathematical statement and proof

Set ν=ΠN\nu=\Pi_Nν=ΠN​ in the three generic statements. By the definition of ΠNθ\Pi_N^\thetaΠNθ​, this yields extended data processing KL⁡(p#μ∥ΠNθ)≤KL⁡(μ∥ΠN)\operatorname{KL}(p_\#\mu\Vert\Pi_N^\theta)\le\operatorname{KL}(\mu\Vert\Pi_N)KL(p#​μ∥ΠNθ​)≤KL(μ∥ΠN​), finiteness of parameter KL whenever joint KL is finite, and any real upper-bound transfer. The proofs are direct specializations and retain normalization of both laws and the finite-joint guard. No additional concentration or optimizer estimate appears in this measure projection step.

Correspondence with the displayed declarations.

  • parameter_kl_le_gibbs_joint: Extended KL data processing with the actual Gibbs parameter target.
  • parameter_kl_ne_top_of_gibbs_joint: Finite actual Gibbs-relative joint KL gives finite parameter KL.
  • parameter_kl_bound_of_gibbs_joint_bound: A joint KL estimate transfers to the actual Gibbs parameter marginal, without constructing a formula for its marginal density.
