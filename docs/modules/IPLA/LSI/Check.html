References and publication status for this development

Unpublished proof

The IPLA LSI proof presented here is unpublished. It derives the joint entropy bound, per-particle normalization, and parameter-marginal consequence by applying the shared ULA entropy theorem to the actual lifted IPLA target. The papers below are background references for that construction.

  • Santosh S. Vempala and Andre Wibisono (2019). Rapid Convergence of the Unadjusted Langevin Algorithm: Isoperimetry Suffices. Advances in Neural Information Processing Systems 32, 8094–8106. Full paper with appendices
  • Alex Glyn-Davies, Connor Duffin, Ieva Kazlauskaite, Mark Girolami, and Ö. Deniz Akyildiz (2025). Statistical Finite Elements via Interacting Particle Langevin Dynamics. SIAM/ASA Journal on Uncertainty Quantification 13(3), 1200–1227. Audited version: arXiv:2409.07101v2

This audit imports the entropy and marginal corollaries and prints their transitive axiom dependencies. Its purpose is to distinguish explicit analytic assumptions from any unintended mathematical axiom or proof placeholder.

Mathematical statement and proof

Run lake env lean IPLA/LSI/Check.lean. The audited chain covers positive-denominator scaling, the actual Gaussian algorithm-law identity, finite KL, derived one-step and iterated bounds, normalized and NαN\alphaNα-LSI specializations, and parameter data processing. The resulting theorems remain conditional on an LSI of the actual lifted target and the displayed RegularInterpolationData. These are ordinary explicit hypotheses, and successful kernel checking does not construct them from LSI and smoothness alone. The audit checks that the completed conditional derivation uses only Lean's usual foundational axioms and no added mathematical axiom.

Each #check command asks Lean to elaborate the complete theorem type, retaining every displayed assumption. Each #print axioms command reports the transitive foundational dependencies of that theorem. Compile this module after the library build to inspect that report; these commands check the existing proofs and do not supply new mathematical hypotheses or conclusions.
